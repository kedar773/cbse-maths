1. Pedagogical Theory, Foundations & Mathematical Intuition

1.1 Intuitive vs. Formal Notion of a Set

Historically formulated by Georg Cantor (1845–1918), set theory forms the foundational language of modern mathematical analysis, topology, and abstract algebra.

Core Definition: The Set

Definition (NCERT): A set is a well-defined collection of distinct objects.

The phrasing "well-defined" is the fundamental mathematical axiom here. A collection is well-defined if and only if there exists an unambiguous logical rule, predicate, or criterion $P(x)$ such that for any given object $x$ in a specified universal domain $U$, the truth value of the proposition $P(x)$ is deterministically either True ($T$) or False ($F$), governed strictly by the Law of the Excluded Middle. No subjective ambiguity is permitted.

  • Non-Well-Defined Collections (Subjective / Vague):
  • "The collection of five most talented mathematicians in the world." (Criteria for "talent" vary subjectively).
  • "The collection of difficult questions in a textbook." (Difficulty is person-dependent).
  • Well-Defined Collections (Mathematical Sets):
  • "The collection of all vowels in the English alphabet." (Elements: $\{a, e, i, o, u\}$).
  • "The collection of all roots of the polynomial equation $x^2 - 5x + 6 = 0$." (Elements: $\{2, 3\}$).

1.2 Notation, Elements, and Membership

  • Notation: Sets are universally denoted by capital English letters: $A, B, C, X, Y, Z, \dots$
  • Elements (or Members/Objects): Denoted by lowercase letters: $a, b, c, x, y, z, \dots$
  • Membership Symbol ($\in$): Derived from the Greek letter epsilon ($\epsilon$ / $\in$, estin meaning "is").
  • If an object $x$ belongs to set $A$, we write:

$$ x \in A \quad \text{("}x\text{ belongs to }A\text{" or "}x\text{ is an element of }A\text{")} $$

  • If an object $x$ does not belong to set $A$, we write:

$$ x \notin A \quad \text{("}x\text{ does not belong to }A\text{")} $$

1.3 Methods of Representing Sets

Method I: Roster or Tabular Form ⭐⭐⭐⭐

All constituent elements are listed explicitly, separated by commas, and enclosed within curly braces { }.

  • Axiom of Order Invariance: The order of listing elements is completely immaterial.

$$ \{1, 2, 3\} = \{3, 1, 2\} = \{2, 3, 1\} $$

  • Axiom of Idempotence / Non-Multiplicity: Repetition of elements does not alter the set. Every element must be listed uniquely.

$$ \text{The set of letters forming the word "COLLEGE"} = \{C, O, L, E, G\} $$

Listing $\{C, O, L, L, E, G, E\}$ is mathematically redundant and deprecated in standard notation.

Method II: Set-Builder or Rule Form ⭐⭐⭐⭐⭐

Instead of listing individual elements, a common defining property (predicate logic formula) $P(x)$ shared by all elements (and by no element outside the set) is stated.

General Syntax:

$$ A = \{ x : P(x) \} \quad \text{or} \quad A = \{ x \mid P(x) \} $$

Read as: "The set of all elements $x$ such that $x$ satisfies the property $P(x)$."

  • Example:
  • Let $V = \{a, e, i, o, u\}$.
  • In Set-Builder form: $V = \{x : x \text{ is a vowel in the English alphabet}\}$.
  • Let $S = \{1, 4, 9, 16, 25, \dots\}$.
  • In Set-Builder form: $S = \{x : x = n^2, \; n \in \mathbb{N}\}$.

1.4 Empty Set (Null Set / Void Set) ⭐⭐⭐⭐⭐

Definition (NCERT): A set which does not contain any element is called the empty set or the null set or the void set.

  • Standard Notation: Denoted by the Scandinavian letter $\emptyset$ (or simply empty braces $\{\}$).
  • Formal Predicate Definition:

$$ \emptyset = \{x : x \neq x\} $$

  • Examples:
  • $A = \{x : 1 < x < 2,\; x \in \mathbb{N}\}$. Since there is no natural number strictly between 1 and 2, $A = \emptyset$.
  • $B = \{x : x^2 - 2 = 0,\; x \in \mathbb{Q}\}$. The roots are $x = \pm\sqrt{2} \notin \mathbb{Q}$; hence $B = \emptyset$.
  • $C = \{x : x \text{ is an even prime number greater than } 2\}$. Since 2 is the only even prime, $C = \emptyset$.

1.5 Finite and Infinite Sets ⭐⭐⭐⭐

Definition (NCERT): A set which is empty or consists of a definite (countable/terminating) number of elements is called finite; otherwise, the set is called infinite.

Cardinal Number of a Finite Set (Cardinality)

The total number of distinct elements present in a finite set $A$ is called the cardinal number (or simply cardinality) of $A$, denoted by $n(A)$ or $|A|$. * If $A = \{2, 4, 6, 8\}$, then $n(A) = 4$. * For the empty set $\emptyset$, $n(\emptyset) = 0$. * If a set $S$ has cardinality $n(S) = k$ where $k \in \mathbb{N} \cup \{0\}$, then $S$ is a finite set.

Infinite Sets

If the process of counting elements never terminates (i.e., cardinality cannot be expressed by any $n \in \mathbb{N} \cup \{0\}$), the set is infinite. * Geometric / Analytic Insight: All elements of an infinite set cannot be listed in roster form if they do not follow an enumerable sequence pattern. - The set of natural numbers $\mathbb{N} = \{1, 2, 3, \dots\}$ has an observable pattern and can be indicated with an ellipsis ($\dots$). - The set of all real numbers $\mathbb{R}$ between 0 and 1 cannot be written in roster form because the elements are uncountably dense; there is no immediate "next" real number after 0. It can only be represented in set-builder form: $\{x : 0 < x < 1, \; x \in \mathbb{R}\}$ or interval notation $(0, 1)$.

2. Complete Mathematical Proofs & Derivations

Theorem 2.1: Uniqueness of the Empty Set ⭐⭐⭐⭐

Theorem Statement: There exists one and only one empty set. (The null set is unique).

Proof:

  • Given: Let there be two empty sets, denoted by $\emptyset_1$ and $\emptyset_2$.
  • To Prove: $\emptyset_1 = \emptyset_2$.
  • Definition of Set Equality: Two sets $A$ and $B$ are equal ($A = B$) if and only if:

$$ \forall x \, (x \in A \iff x \in B) $$

which is equivalent to proving that $A \subseteq B$ and $B \subseteq A$.

  1. Consider the proposition $\emptyset_1 \subseteq \emptyset_2$: By formal conditional logic, a subset relation is defined as:

$$ A \subseteq B \iff \forall x \, (x \in A \implies x \in B) $$

Let $x$ be an arbitrary element. Evaluate the implication:

$$ x \in \emptyset_1 \implies x \in \emptyset_2 $$

By the fundamental definition of an empty set, the hypothesis "$x \in \emptyset_1$" is identically False for all possible entities $x$. In classical logic, a conditional statement $P \implies Q$ is vacuously True whenever the antecedent $P$ is False, irrespective of the truth value of the consequent $Q$. Therefore:

$$ \forall x \, (x \in \emptyset_1 \implies x \in \emptyset_2) \equiv \text{True} \implies \emptyset_1 \subseteq \emptyset_2 \quad \text{--- (Equation 1)} $$

  1. Consider the reverse proposition $\emptyset_2 \subseteq \emptyset_1$: Applying identical logical reasoning: The hypothesis "$x \in \emptyset_2$" is identically False for all $x$. Thus, the implication:

$$ x \in \emptyset_2 \implies x \in \emptyset_1 $$

is vacuously True for all $x$. Therefore:

$$ \emptyset_2 \subseteq \emptyset_1 \quad \text{--- (Equation 2)} $$

  1. Synthesis: From (Equation 1) and (Equation 2), by the Axiom of Extensionality:

$$ \emptyset_1 \subseteq \emptyset_2 \quad \text{and} \quad \emptyset_2 \subseteq \emptyset_1 \implies \emptyset_1 = \emptyset_2 $$

Hence, the empty set is unique.

$$ \tag*{Q.E.D.} $$

Theorem 2.2: Equivalence Criterion of Set Representation Systems ⭐⭐⭐

Theorem Statement: Let $A = \{x \in \mathbb{R} : ax^2 + bx + c = 0 \text{ with } a \neq 0 \text{ and } D = b^2 - 4ac\}$. Then $A$ is finite, and its cardinality satisfies $n(A) \in \{0, 1, 2\}$.

Proof:

  • Given: Quadratic equation $ax^2 + bx + c = 0$ over $\mathbb{R}$, $a \neq 0$.

  • To Prove: $A$ is finite, with $n(A) \in \{0, 1, 2\}$.

  • By the algebraic completion of squares:

$$ ax^2 + bx + c = 0 \iff x^2 + \frac{b}{a}x + \frac{c}{a} = 0 $$

$$ \left(x + \frac{b}{2a}\right)^2 - \frac{b^2}{4a^2} + \frac{c}{a} = 0 $$

$$ \left(x + \frac{b}{2a}\right)^2 = \frac{b^2 - 4ac}{4a^2} = \frac{D}{4a^2} $$

  1. Case Analysis over the Real Domain $\mathbb{R}$:
  2. Case I: $D < 0$ The left side $\left(x + \frac{b}{2a}\right)^2 \ge 0$ for all $x \in \mathbb{R}$, whereas $\frac{D}{4a^2} < 0$. No real number satisfies this equality.

$$ A = \emptyset \implies n(A) = 0 $$

  • Case II: $D = 0$

$$ \left(x + \frac{b}{2a}\right)^2 = 0 \implies x = -\frac{b}{2a} $$

 By the Axiom of Idempotence, multiple identical roots are listed once in a set:

$$ A = \left\{-\frac{b}{2a}\right\} \implies n(A) = 1 $$

  • Case III: $D > 0$

$$ x + \frac{b}{2a} = \pm \frac{\sqrt{D}}{2a} \implies x = \frac{-b \pm \sqrt{D}}{2a} $$

 Since $\sqrt{D} \neq 0$, these two roots are distinct real numbers:

$$ A = \left\{\frac{-b - \sqrt{D}}{2a}, \frac{-b + \sqrt{D}}{2a}\right\} \implies n(A) = 2 $$

  1. In all cases, $n(A)$ is a non-negative integer $\le 2$. Thus, $A$ is strictly finite.

$$ \tag*{Q.E.D.} $$

3. High-Yield Examples & NCERT Exemplar Problems

Problem 3.1 (NCERT Exemplar — Complex Set-Builder to Roster Conversion)

Problem: Write the following set in Roster Form:

$$ A = \left\{ x \in \mathbb{Z} : x^3 - 7x^2 + 14x - 8 = 0 \right\} $$

Step-by-Step Solution:

  • Step 1 (Polynomial Factorization): Let $P(x) = x^3 - 7x^2 + 14x - 8$. Testing integer divisors of the constant term $-8$: $\pm 1, \pm 2, \pm 4, \pm 8$. For $x = 1$:

$$ P(1) = (1)^3 - 7(1)^2 + 14(1) - 8 = 1 - 7 + 14 - 8 = 0 $$

By the Factor Theorem, $(x - 1)$ is a factor of $P(x)$. <span class="step-mark-tag">[1 Mark]</span>

  • Step 2 (Synthetic Division / Algebraic Division): Factorize $P(x)$ by dividing by $(x - 1)$:

$$ x^3 - 7x^2 + 14x - 8 = (x - 1)(x^2 - 6x + 8) $$

Factor the remaining quadratic expression:

$$ x^2 - 6x + 8 = x^2 - 4x - 2x + 8 = (x - 2)(x - 4) $$

Therefore, the polynomial equation factorizes completely into:

$$ (x - 1)(x - 2)(x - 4) = 0 \implies x \in \{1, 2, 4\} $$

<span class="step-mark-tag">[1 Mark]</span>

  • Step 3 (Constraint Verification & Roster Formulation): Verify domain constraint: $1 \in \mathbb{Z}$, $2 \in \mathbb{Z}$, $4 \in \mathbb{Z}$. All solutions are valid distinct integers.

$$ A = \{1, 2, 4\} $$

<span class="step-mark-tag">[1 Mark]</span>

Problem 3.2 (NCERT Formative — Roster to Set-Builder Conversion)

Problem: Write the set $S$ in Set-Builder Form:

$$ S = \left\{ \frac{1}{2}, \frac{2}{5}, \frac{3}{10}, \frac{4}{17}, \frac{5}{26}, \frac{6}{37} \right\} $$

Step-by-Step Solution:

  • Step 1 (Pattern Discovery): Analyze the numerators:

$$ \text{Numerators} = 1, 2, 3, 4, 5, 6 \implies n \in \mathbb{N} \quad (1 \le n \le 6) $$

Analyze the denominators relative to $n$: - For $n = 1$: Denominator $= 2 = 1^2 + 1$ - For $n = 2$: Denominator $= 5 = 2^2 + 1$ - For $n = 3$: Denominator $= 10 = 3^2 + 1$ - For $n = 4$: Denominator $= 17 = 4^2 + 1$ - For $n = 5$: Denominator $= 26 = 5^2 + 1$ - For $n = 6$: Denominator $= 37 = 6^2 + 1$ <span class="step-mark-tag">[1.5 Marks]</span>

  • Step 2 (Formulating the Predicate): The $n$-th term is given by the algebraic expression:

$$ T_n = \frac{n}{n^2 + 1} $$

<span class="step-mark-tag">[0.5 Mark]</span>

  • Step 3 (Formal Set-Builder Statement):

$$ S = \left\{ x : x = \frac{n}{n^2 + 1}, \; n \in \mathbb{N} \text{ and } 1 \le n \le 6 \right\} $$

<span class="step-mark-tag">[1 Mark]</span>

Problem 3.3 (Rigorous Classification: Empty, Finite, or Infinite)

Problem: Classify the following sets as Empty, Finite, or Infinite, giving rigorous justifications: 1. $E_1 = \{x \in \mathbb{N} : (x - 1)(x - 2) = 0\}$ 2. $E_2 = \{x \in \mathbb{N} : x \text{ is prime and } x \text{ is even}\}$ 3. $E_3 = \{x \in \mathbb{Z} : x^2 \le 9\}$ 4. $E_4 = \{x \in \mathbb{R} : 0 < x < 1\}$ 5. $E_5 = \{x \in \mathbb{Q} : x^2 = 3\}$

Step-by-Step Solution:

  • Part 1: $(x - 1)(x - 2) = 0 \implies x = 1$ or $x = 2$. Both $1, 2 \in \mathbb{N}$.

$$ E_1 = \{1, 2\} \implies n(E_1) = 2 $$

Conclusion: $E_1$ is Finite. <span class="step-mark-tag">[0.5 Mark]</span>

  • Part 2: The only even prime number in the natural numbers is $2$.

$$ E_2 = \{2\} \implies n(E_2) = 1 $$

Conclusion: $E_2$ is a Singleton Set (hence Finite). <span class="step-mark-tag">[0.5 Mark]</span>

  • Part 3: $x^2 \le 9 \implies -3 \le x \le 3$. Since $x \in \mathbb{Z}$, the explicit values are $\{-3, -2, -1, 0, 1, 2, 3\}$.

$$ n(E_3) = 7 $$

Conclusion: $E_3$ is Finite. <span class="step-mark-tag">[1 Mark]</span>

  • Part 4: The real numbers are uncountably dense. Between any two distinct real numbers $a < b$, there exist infinitely many real numbers. Conclusion: $E_4$ is Infinite. <span class="step-mark-tag">[1 Mark]</span>

  • Part 5: $x^2 = 3 \implies x = \pm\sqrt{3}$. Since $\sqrt{3}$ is an irrational number, $\sqrt{3} \notin \mathbb{Q}$ and $-\sqrt{3} \notin \mathbb{Q}$. Therefore, no element satisfies both conditions.

$$ E_5 = \emptyset $$

Conclusion: $E_5$ is the Empty Set (which is, by definition, Finite with cardinality 0). <span class="step-mark-tag">[1 Mark]</span>

4. Examiner Traps & Common Student Pitfalls

❌ TRAP 1: Confusing Empty Set Notation
   Student writes: A = { ∅ }
   CRITICAL ERROR: { ∅ } is NOT the empty set!
   • ∅ has cardinality: n(∅) = 0
   • { ∅ } is a non-empty singleton set containing the element ∅; its cardinality is n({ ∅ }) = 1.
   CORRECT NOTATION: Write either ∅ or { }. Never put ∅ inside braces.

❌ TRAP 2: Confusing 0 with the Empty Set
   Student writes: A = { 0 } = ∅
   CRITICAL ERROR: 0 is an integer element!
   • { 0 } is a singleton set containing the number zero: n({ 0 }) = 1.
   • ∅ contains no elements: n(∅) = 0.
   Therefore, { 0 } ≠ ∅.

❌ TRAP 3: Overlooking Domain Constraints in Set-Builder Form
   Given: S = { x ∈ N : 2x - 5 = 0 }
   Student writes: S = { 5/2 }
   CRITICAL ERROR: The domain specified is x ∈ N (Natural numbers).
   Since 5/2 = 2.5 ∉ N, no element satisfies the predicate.
   CORRECT ANSWER: S = ∅.

❌ TRAP 4: Violating the Axiom of Idempotence in Roster Form
   Word: "MATHEMATICS"
   Student writes: {M, A, T, H, E, M, A, T, I, C, S}
   CRITICAL ERROR: Deductions occur under CBSE marking schemes for redundant elements.
   CORRECT FORM: {M, A, T, H, E, I, C, S} (Cardinality = 8).

❌ TRAP 5: Misidentifying Continuity vs. Discreteness in Infinite Sets
   Given: A = { x ∈ N : 1 < x < 2 }  →  A = ∅ (Discrete natural numbers)
   Given: B = { x ∈ R : 1 < x < 2 }  →  B is INFINITE (Continuous real interval)
   Exam Tip: Always double-check the underlying field: N, Z, Q, or R.

1. Concept of Subsets ($\subseteq$)

Star Priority: ⭐⭐⭐⭐⭐ (Core Foundation of Set Theory & Board/JEE Gateway)

1.1 Formal Definition & Symbolism

Let $A$ and $B$ be two sets defined in the same universe of discourse. Set $A$ is said to be a subset of set $B$ if every element belonging to $A$ also belongs to $B$.

In formal first-order predicate logic:

$$ A \subseteq B \iff \big(\forall x \, (x \in A \implies x \in B)\big) $$

  • If $A$ is a subset of $B$, we write $A \subseteq B$ ($A$ is contained in $B$).
  • Alternatively, we state that $B$ is a superset of $A$, denoted by $B \supseteq A$.
  • If there exists at least one element $x \in A$ such that $x \notin B$, then $A$ is not a subset of $B$, denoted by:

$$ A \nsubseteq B \iff \exists x \, (x \in A \land x \notin B) $$

1.2 Proper Subset ($\subset$) vs. Improper Subset

  • Improper Subset: Every set $A$ is an improper subset of itself ($A \subseteq A$).
  • Proper Subset: Set $A$ is a proper subset of set $B$ (denoted $A \subset B$) if and only if:
  • $A \subseteq B$, and
  • $A \neq B$ (i.e., $\exists y \in B \text{ such that } y \notin A$).

$$ \begin{array}{|l|l|l|} \hline Relation & Symbol & Formal Condition \\ \hline \text{Subset (General)} & A \subseteq B & \forall x \in A \implies x \in B \\ \hline \text{Proper Subset} & A \subset B & A \subseteq B \text{ and } A \neq B \\ \hline \text{Superset} & B \supseteq A & A \subseteq B \\ \hline \text{Not a Subset} & A \nsubseteq B & \exists x \in A \text{ such that } x \notin B \\ \hline \end{array} $$

1.3 Geometric & Euler-Venn Interpretation

In a Venn diagram: - If $A \subseteq B$, the closed planar curve (disk/ellipse) representing set $A$ lies strictly entirely inside the planar curve representing set $B$. - The region $A \setminus B = \emptyset$.

2. Subsets of Real Numbers ($\mathbb{R}$)

Star Priority: ⭐⭐⭐⭐ (Crucial for Functions, Calculus & Coordinate Geometry)

2.1 Standard Number Systems Hierarchy

The set of real numbers $\mathbb{R}$ exhibits a foundational chain of subset inclusions:

$$ \mathbb{N} \subset \mathbb{W} \subset \mathbb{Z} \subset \mathbb{Q} \subset \mathbb{R} $$

  • Natural Numbers:

$$ \mathbb{N} = \{1, 2, 3, 4, 5, \dots\} $$

  • Whole Numbers:

$$ \mathbb{W} = \{0, 1, 2, 3, 4, \dots\} = \mathbb{N} \cup \{0\} $$

  • Integers:

$$ \mathbb{Z} = \{\dots, -3, -2, -1, 0, 1, 2, 3, \dots\} $$

  • Rational Numbers:

$$ \mathbb{Q} = \left\{ \frac{p}{q} \;\middle|\; p, q \in \mathbb{Z}, \, q \neq 0, \, \gcd(p, q) = 1 \right\} $$

  • Irrational Numbers ($\mathbb{T}$ or $\mathbb{R} \setminus \mathbb{Q}$): Real numbers whose decimal expansions are non-terminating and non-repeating:

$$ \mathbb{T} = \{x \in \mathbb{R} \mid x \notin \mathbb{Q}\} $$

Notice: $\mathbb{Q} \cup \mathbb{T} = \mathbb{R}$ and $\mathbb{Q} \cap \mathbb{T} = \emptyset$.

3. Intervals as Subsets of $\mathbb{R}$

Star Priority: ⭐⭐⭐⭐⭐ (Heavily Tested in Domain/Range, Inequalities, Limits & Calculus)

Let $a, b \in \mathbb{R}$ such that $a < b$. The set of real numbers lying between $a$ and $b$ forms continuous subsets of $\mathbb{R}$ termed intervals.

3.1 Finite (Bounded) Intervals

  1. Open Interval:

$$ (a, b) = \{x \in \mathbb{R} \mid a < x < b\} $$

Number Line: Points $a$ and $b$ are excluded (hollow circles $\circ$).

  1. Closed Interval:

$$ [a, b] = \{x \in \mathbb{R} \mid a \le x \le b\} $$

Number Line: Points $a$ and $b$ are included (solid dots $\bullet$).

  1. Semi-Open / Semi-Closed Intervals:
  2. Left-Closed, Right-Open:

$$ [a, b) = \{x \in \mathbb{R} \mid a \le x < b\} $$

 ($a$ included $\bullet$, $b$ excluded $\circ$).
  • Left-Open, Right-Closed:

$$ (a, b] = \{x \in \mathbb{R} \mid a < x \le b\} $$

 ($a$ excluded $\circ$, $b$ included $\bullet$).

Length of any bounded interval $(a, b)$, $[a, b]$, $[a, b)$, or $(a, b]$ is defined as:

$$ \text{Length} = b - a $$

3.2 Infinite (Unbounded) Intervals

  • $[a, \infty) = \{x \in \mathbb{R} \mid x \ge a\}$
  • $(a, \infty) = \{x \in \mathbb{R} \mid x > a\}$
  • $(-\infty, b] = \{x \in \mathbb{R} \mid x \le b\}$
  • $(-\infty, b) = \{x \in \mathbb{R} \mid x < b\}$
  • $(-\infty, \infty) = \mathbb{R}$

(Note: The symbols $\infty$ and $-\infty$ are not real numbers; hence brackets adjacent to $\pm\infty$ are always parenthesis ) or ().

4. Power Set ($\mathcal{P}(A)$)

Star Priority: ⭐⭐⭐⭐⭐ (Frequent Direct Question in Class 11 Board Exams & Olympiads)

4.1 Definition

The Power Set of a given set $A$, denoted by $\mathcal{P}(A)$, is the collection/set of all possible subsets of $A$.

$$ \mathcal{P}(A) = \{X \mid X \subseteq A\} $$

4.2 Properties of Power Sets

  1. Always Non-Empty: For every set $A$, $\emptyset \in \mathcal{P}(A)$ and $A \in \mathcal{P}(A)$. Thus, $\mathcal{P}(A) \neq \emptyset$ even if $A = \emptyset$.
  2. Elements vs. Subsets: If $X \in \mathcal{P}(A)$, then $X \subseteq A$.
  3. Cardinality: If $n(A) = m$, then $n(\mathcal{P}(A)) = 2^m$.
  4. Proper Subsets Count: The total number of proper subsets of $A$ is $2^m - 1$.
  5. Non-Empty Subsets Count: The total number of non-empty subsets of $A$ is $2^m - 1$.
  6. Non-Empty Proper Subsets Count: $2^m - 2$ (excluding $\emptyset$ and $A$).

5. Universal Set ($U$)

Star Priority: ⭐⭐⭐ (Contextual Master Set)

A set containing all possible objects/elements under consideration for a specific mathematical context or discussion is called the Universal Set, denoted by $\mathcal{U}$ or $U$. - In plane coordinate geometry: $U = \mathbb{R}^2 = \{(x, y) \mid x, y \in \mathbb{R}\}$. - In the study of real numbers: $U = \mathbb{R}$. - Every set $A$ under investigation is a subset of the chosen universal set: $A \subseteq U$.

SECTION 2: Complete Mathematical Proofs & Derivations

Theorem 1: The Empty Set is a Subset of Every Set

$$ \text{For every set } A, \quad \emptyset \subseteq A $$

  • Given: A set $A$ and the empty set $\emptyset$ containing no elements ($\forall x, \, x \notin \emptyset$).
  • To Prove: $\emptyset \subseteq A$.
  • Method: Proof by Contradiction (and Vacuous Truth).

Step-by-Step Proof: Assume the negation of the proposition.

$$ \neg(\emptyset \subseteq A) \iff \emptyset \nsubseteq A $$

By definition of a subset, $\emptyset \nsubseteq A$ holds if and only if there exists an element $x$ such that:

$$ x \in \emptyset \quad \text{and} \quad x \notin A $$

However, by the fundamental axiom of the null set:

$$ \forall x, \quad x \notin \emptyset $$

This produces a direct logical contradiction:

$$ (x \in \emptyset) \land (x \notin \emptyset) \equiv \bot \; (\text{Contradiction}) $$

Hence, the assumption that $\emptyset \nsubseteq A$ must be false.

$$ \therefore \emptyset \subseteq A $$

$$ \tag*{Q.E.D.} $$

Theorem 2: Reflexivity of the Subset Relation

$$ \text{Every set is a subset of itself, i.e., } A \subseteq A $$

  • Given: Any arbitrary set $A$.
  • To Prove: $A \subseteq A$.

Step-by-Step Proof: Let $x$ be an arbitrary element such that:

$$ x \in A $$

From classical propositional logic, the implication $P \implies P$ is a tautology:

$$ x \in A \implies x \in A $$

Since this implication holds for all arbitrary $x$:

$$ \forall x \, (x \in A \implies x \in A) $$

By the formal definition of a subset:

$$ A \subseteq A $$

$$ \tag*{Q.E.D.} $$

Theorem 3: Antisymmetry of the Subset Relation (Criterion for Set Equality)

$$ A = B \iff (A \subseteq B \text{ and } B \subseteq A) $$

  • Given: Two sets $A$ and $B$.
  • To Prove: $A = B \iff (A \subseteq B \land B \subseteq A)$.

Step-by-Step Proof:

Part 1: $(\implies)$ If $A = B$, then $A \subseteq B$ and $B \subseteq A$. 1. Assume $A = B$. By the Axiom of Extensionality:

$$ \forall x \, (x \in A \iff x \in B) $$

  1. The biconditional $(x \in A \iff x \in B)$ implies two conditional statements:

$$ (x \in A \implies x \in B) \quad \text{and} \quad (x \in B \implies x \in A) $$

  1. Since $\forall x \, (x \in A \implies x \in B)$, by definition, $A \subseteq B$.
  2. Since $\forall x \, (x \in B \implies x \in A)$, by definition, $B \subseteq A$.
  3. Therefore, $A \subseteq B \land B \subseteq A$.

Part 2: $(\impliedby)$ If $A \subseteq B$ and $B \subseteq A$, then $A = B$. 1. Assume $A \subseteq B$ and $B \subseteq A$. 2. $A \subseteq B \implies \forall x \, (x \in A \implies x \in B)$. 3. $B \subseteq A \implies \forall x \, (x \in B \implies x \in A)$. 4. Combining both implications yields the logical equivalence:

$$ \forall x \, (x \in A \iff x \in B) $$

  1. By the Axiom of Extensionality, two sets sharing identical elements are equal:

$$ A = B $$

$$ \therefore A = B \iff (A \subseteq B \land B \subseteq A) $$

$$ \tag*{Q.E.D.} $$

Theorem 4: Transitivity of the Subset Relation

$$ \text{If } A \subseteq B \text{ and } B \subseteq C, \text{ then } A \subseteq C $$

  • Given: $A \subseteq B$ and $B \subseteq C$.
  • To Prove: $A \subseteq C$.

Step-by-Step Proof: Let $x$ be an arbitrary element such that:

$$ x \in A $$

Since $A \subseteq B$:

$$ x \in A \implies x \in B $$

Therefore, $x \in B$.

Since $B \subseteq C$:

$$ x \in B \implies x \in C $$

Therefore, $x \in C$.

We have demonstrated that for an arbitrary element $x$:

$$ x \in A \implies x \in C $$

Since this holds universally:

$$ \forall x \, (x \in A \implies x \in C) \iff A \subseteq C $$

$$ \tag*{Q.E.D.} $$

Theorem 5: Cardinality of the Power Set of a Finite Set

$$ \text{If } n(A) = m \text{ where } m \in \mathbb{N}_0, \text{ then } n(\mathcal{P}(A)) = 2^m $$

We present two rigorous proofs: Proof A (Combinatorial/Binomial Theorem) and Proof B (Mathematical Induction).

Proof A: Combinatorial Derivation via Binomial Theorem

Let set $A = \{a_1, a_2, \dots, a_m\}$ have $m$ distinct elements. Any subset $S \subseteq A$ can contain $0, 1, 2, \dots, \text{ or } m$ elements: - Number of subsets having $0$ elements = $\binom{m}{0}$ - Number of subsets having $1$ element = $\binom{m}{1}$ - Number of subsets having $2$ elements = $\binom{m}{2}$ - $\dots$ - Number of subsets having $k$ elements = $\binom{m}{k}$ - Number of subsets having $m$ elements = $\binom{m}{m}$

By the Rule of Sum, the total number of distinct subsets $n(\mathcal{P}(A))$ is:

$$ n(\mathcal{P}(A)) = \sum_{k=0}^{m} \binom{m}{k} = \binom{m}{0} + \binom{m}{1} + \binom{m}{2} + \dots + \binom{m}{m} $$

From the Binomial Expansion of $(1 + x)^m$:

$$ (1 + x)^m = \sum_{k=0}^{m} \binom{m}{k} x^k $$

Substituting $x = 1$:

$$ (1 + 1)^m = \sum_{k=0}^{m} \binom{m}{k} (1)^k \implies 2^m = \sum_{k=0}^{m} \binom{m}{k} $$

$$ \therefore n(\mathcal{P}(A)) = 2^m $$

$$ \tag*{Q.E.D.} $$

Proof B: Derivation by Mathematical Induction on $m$

  • Proposition $P(m)$: A set containing $m$ elements has $2^m$ subsets.

Base Step ($m = 0$): Let $A = \emptyset$. Here $n(A) = 0$. The only subset of $\emptyset$ is $\emptyset$ itself.

$$ \mathcal{P}(\emptyset) = \{\emptyset\} \implies n(\mathcal{P}(\emptyset)) = 1 = 2^0 $$

Thus, $P(0)$ is true.

Inductive Hypothesis: Assume that $P(k)$ is true for some integer $k \ge 0$. That is, any set $A_k$ with $n(A_k) = k$ has:

$$ n(\mathcal{P}(A_k)) = 2^k $$

Inductive Step: Consider a set $A_{k+1}$ having $k+1$ elements:

$$ A_{k+1} = A_k \cup \{x_{k+1}\} \quad \text{where } x_{k+1} \notin A_k $$

Subsets of $A_{k+1}$ can be partitioned into two mutually exclusive and exhaustive categories: 1. Subsets that do not contain $x_{k+1}$: These are precisely the subsets of $A_k$.

$$ \text{Count}_1 = n(\mathcal{P}(A_k)) = 2^k $$

  1. Subsets that contain $x_{k+1}$: Each such subset is formed by taking a subset $S \in \mathcal{P}(A_k)$ and forming $S \cup \{x_{k+1}\}$. Since there are $2^k$ subsets in $\mathcal{P}(A_k)$, there are exactly $2^k$ such new subsets.

$$ \text{Count}_2 = 2^k $$

Total subsets of $A_{k+1}$:

$$ n(\mathcal{P}(A_{k+1})) = \text{Count}_1 + \text{Count}_2 = 2^k + 2^k = 2 \cdot 2^k = 2^{k+1} $$

Therefore, $P(k+1)$ is true whenever $P(k)$ is true. By the Principle of Mathematical Induction, $P(m)$ is true for all $m \in \mathbb{N}_0$.

$$ \tag*{Q.E.D.} $$

Theorem 6: Distributive Properties of Power Sets

$$ \text{For any two sets } A \text{ and } B: $$

$$ 1. \; \mathcal{P}(A) \cap \mathcal{P}(B) = \mathcal{P}(A \cap B) $$

$$ 2. \; \mathcal{P}(A) \cup \mathcal{P}(B) \subseteq \mathcal{P}(A \cup B) \quad (\text{Equality does not hold in general!}) $$

Proof of Part 1: $\mathcal{P}(A) \cap \mathcal{P}(B) = \mathcal{P}(A \cap B)$

Let $X$ be an arbitrary set.

$$ X \in \big(\mathcal{P}(A) \cap \mathcal{P}(B)\big) $$

$$ \iff \big(X \in \mathcal{P}(A)\big) \land \big(X \in \mathcal{P}(B)\big) $$

$$ \iff (X \subseteq A) \land (X \subseteq B) $$

$$ \iff \forall x \, (x \in X \implies x \in A) \land \forall x \, (x \in X \implies x \in B) $$

$$ \iff \forall x \, \big(x \in X \implies (x \in A \land x \in B)\big) $$

$$ \iff \forall x \, (x \in X \implies x \in (A \cap B)) $$

$$ \iff X \subseteq (A \cap B) $$

$$ \iff X \in \mathcal{P}(A \cap B) $$

Since every step is a bidirectional logical equivalence ($\iff$):

$$ \mathcal{P}(A) \cap \mathcal{P}(B) = \mathcal{P}(A \cap B) $$

$$ \tag*{Q.E.D.} $$

Proof of Part 2: $\mathcal{P}(A) \cup \mathcal{P}(B) \subseteq \mathcal{P}(A \cup B)$

Let $X \in \big(\mathcal{P}(A) \cup \mathcal{P}(B)\big)$.

$$ \implies \big(X \in \mathcal{P}(A)\big) \lor \big(X \in \mathcal{P}(B)\big) $$

$$ \implies (X \subseteq A) \lor (X \subseteq B) $$

Since $A \subseteq (A \cup B)$ and $B \subseteq (A \cup B)$: - If $X \subseteq A$, then by transitivity $X \subseteq (A \cup B)$. - If $X \subseteq B$, then by transitivity $X \subseteq (A \cup B)$.

In either case:

$$ X \subseteq (A \cup B) \implies X \in \mathcal{P}(A \cup B) $$

Thus:

$$ \mathcal{P}(A) \cup \mathcal{P}(B) \subseteq \mathcal{P}(A \cup B) $$

$$ \tag*{Q.E.D.} $$

(Counterexample showing non-equality is demonstrated in Section 3, Problem 4).

Problem 1: Step-by-Step Writing of Power Sets

Statement: Let $A = \{\emptyset, 1, \{2, 3\}\}$. 1. Find $n(A)$. 2. List all elements of $\mathcal{P}(A)$. 3. Determine the truth value of: - (i) $\emptyset \in A$ - (ii) $\emptyset \subseteq A$ - (iii) $\{\emptyset\} \subseteq A$ - (iv) $\{2, 3\} \in A$ - (v) $\{2, 3\} \subseteq A$ - (vi) $\{\{2, 3\}\} \subseteq A$

Solution & Step-by-Step Scoring:

  • Step 1: Determine $n(A)$ and cardinality of $\mathcal{P}(A)$ The distinct elements of set $A$ are:
  • Element 1: $\emptyset$
  • Element 2: $1$
  • Element 3: $\{2, 3\}$

$$ n(A) = 3 \implies n(\mathcal{P}(A)) = 2^3 = 8 \text{ elements.} $$

(Marks: 1)

  • Step 2: Systematic listing of all 8 subsets in $\mathcal{P}(A)$
  • Subsets of size 0 (1 subset):

$$ \emptyset $$

  • Subsets of size 1 (3 subsets):

$$ \{\emptyset\}, \quad \{1\}, \quad \{\{2, 3\}\} $$

  • Subsets of size 2 (3 subsets):

$$ \{\emptyset, 1\}, \quad \{\emptyset, \{2, 3\}\}, \quad \{1, \{2, 3\}\} $$

  • Subsets of size 3 (1 subset):

$$ \{\emptyset, 1, \{2, 3\}\} = A $$

Therefore:

$$ \mathcal{P}(A) = \Big\{ \emptyset, \, \{\emptyset\}, \, \{1\}, \, \{\{2, 3\}\}, \, \{\emptyset, 1\}, \, \{\emptyset, \{2, 3\}\}, \, \{1, \{2, 3\}\}, \, A \Big\} $$

(Marks: 2)

  • Step 3: Verification of Truth Values
  • (i) $\emptyset \in A$: TRUE (Since $\emptyset$ is explicitly an element of $A$).
  • (ii) $\emptyset \subseteq A$: TRUE (The empty set is a subset of every set).
  • (iii) $\{\emptyset\} \subseteq A$: TRUE (Singleton set containing the element $\emptyset \in A$).
  • (iv) $\{2, 3\} \in A$: TRUE (The object $\{2, 3\}$ is an element of $A$).
  • (v) $\{2, 3\} \subseteq A$: FALSE (The numbers $2$ and $3$ are not individual elements of $A$; $2 \notin A, 3 \notin A$).
  • (vi) $\{\{2, 3\}\} \subseteq A$: TRUE (The singleton containing $\{2, 3\}$ forms a subset of $A$). (Marks: 3)

Problem 2: NCERT Exemplar — Simultaneous Linear Subsets Equation

Statement: Two finite sets $A$ and $B$ have $m$ and $k$ elements respectively. The total number of subsets of the first set is 56 more than the total number of subsets of the second set. Find the values of $m$ and $k$.

Solution:

  • Step 1: Set up the algebraic equation based on definitions Let $n(A) = m$ and $n(B) = k$. Number of subsets of $A = 2^m$. Number of subsets of $B = 2^k$.

According to the problem statement:

$$ 2^m - 2^k = 56 $$

(Marks: 1)

  • Step 2: Algebraic factorisation of binary powers Since $56 > 0$, we have $2^m > 2^k \implies m > k$. Factor out the lowest power $2^k$:

$$ 2^k (2^{m-k} - 1) = 56 $$

(Marks: 1)

  • Step 3: Prime factorisation of 56 into even and odd components Express $56$ as the product of a power of 2 and an odd integer:

$$ 56 = 8 \times 7 = 2^3 \times (2^3 - 1) $$

So:

$$ 2^k (2^{m-k} - 1) = 2^3 (7) $$

(Marks: 1)

  • Step 4: Equating corresponding components Since $2^k$ is a pure power of 2 (even for $k \ge 1$) and $(2^{m-k} - 1)$ is strictly odd:

$$ 2^k = 2^3 \implies k = 3 $$

$$ 2^{m-k} - 1 = 7 \implies 2^{m-k} = 8 = 2^3 \implies m - k = 3 $$

Substitute $k = 3$:

$$ m - 3 = 3 \implies m = 6 $$

  • Verification:

$$ 2^6 = 64, \quad 2^3 = 8 \implies 64 - 8 = 56 \quad \text{(Verified)} $$

Final Answer: $m = 6, \quad k = 3$. (Marks: 1)

Problem 3: Interval Arithmetic, Inclusions, and Set Operations

Statement: Let $U = \mathbb{R}$. Given intervals:

$$ A = [-4, 3), \quad B = (-1, 5], \quad C = [2, \infty) $$

Find: 1. $A \cap B$ 2. $A \cup B$ 3. $A \setminus B$ 4. $B \cap C'$ (where $C' = U \setminus C$) Write all answers in standard interval notation.

Solution:

  • Step 1: Find $A \cap B$

$$ A = \{x \in \mathbb{R} \mid -4 \le x < 3\} $$

$$ B = \{x \in \mathbb{R} \mid -1 < x \le 5\} $$

The intersection requires both conditions to hold:

$$ -1 < x < 3 \implies A \cap B = (-1, 3) $$

(Marks: 1)

  • Step 2: Find $A \cup B$ The union covers the entire contiguous range from the leftmost point of $A$ to the rightmost point of $B$:

$$ \text{Left boundary: } -4 \text{ (included, } [) $$

$$ \text{Right boundary: } 5 \text{ (included, } ]) $$

$$ A \cup B = [-4, 5] $$

(Marks: 1)

  • Step 3: Find $A \setminus B$ $A \setminus B$ consists of elements that belong to $A$ but DO NOT belong to $B$.

$$ A \setminus B = [-4, 3) \setminus (-1, 5] $$

Since $B$ begins strictly after $-1$ (i.e., $x > -1$), removing $B$ leaves all points in $A$ up to and including $-1$.

$$ A \setminus B = [-4, -1] $$

(Notice: $-1 \notin B$, so $-1$ is retained in $A \setminus B$; hence closed at $-1$). (Marks: 1)

  • Step 4: Find $B \cap C'$

$$ C = [2, \infty) \implies C' = \mathbb{R} \setminus [2, \infty) = (-\infty, 2) $$

Now intersect $B = (-1, 5]$ with $C' = (-\infty, 2)$:

$$ B \cap C' = (-1, 5] \cap (-\infty, 2) = (-1, 2) $$

(Marks: 1)

Problem 4: Strict Counterexample for $\mathcal{P}(A) \cup \mathcal{P}(B) \neq \mathcal{P}(A \cup B)$

Statement: Show by constructing an explicit counterexample that $\mathcal{P}(A) \cup \mathcal{P}(B) \neq \mathcal{P}(A \cup B)$ in general.

Solution: - Step 1: Choose minimal distinct non-empty sets Let $A = \{1\}$ and $B = \{2\}$. (Marks: 1)

  • Step 2: Compute individual power sets and their union

$$ \mathcal{P}(A) = \{\emptyset, \{1\}\} $$

$$ \mathcal{P}(B) = \{\emptyset, \{2\}\} $$

$$ \mathcal{P}(A) \cup \mathcal{P}(B) = \{\emptyset, \{1\}, \{2\}\} $$

Notice that $n\big(\mathcal{P}(A) \cup \mathcal{P}(B)\big) = 3$. (Marks: 1)

  • Step 3: Compute the power set of the union

$$ A \cup B = \{1, 2\} $$

$$ \mathcal{P}(A \cup B) = \{\emptyset, \{1\}, \{2\}, \{1, 2\}\} $$

Notice that $n\big(\mathcal{P}(A \cup B)\big) = 4$. (Marks: 1)

  • Step 4: Comparison and Conclusion The set $\{1, 2\} \in \mathcal{P}(A \cup B)$, but $\{1, 2\} \notin \big(\mathcal{P}(A) \cup \mathcal{P}(B)\big)$.

$$ \therefore \mathcal{P}(A) \cup \mathcal{P}(B) \subsetneq \mathcal{P}(A \cup B) $$

Hence, equality does not hold in general. (Marks: 1)

2. The Binary Representation Code (Mental Generation of Subsets)

To mentally list all subsets of $A = \{x_1, x_2, \dots, x_m\}$ without missing any: - Associate each subset with an $m$-bit binary word: $b_m b_{m-1} \dots b_1$ where $b_i \in \{0, 1\}$. - $b_i = 1$ indicates inclusion of element $x_i$; $b_i = 0$ indicates exclusion. - Counting in binary from $0$ to $2^m - 1$ yields every subset uniquely: - For $A = \{a, b\}$ ($m = 2$): - $00_2 = 0 \implies \emptyset$ - $01_2 = 1 \implies \{a\}$ - $10_2 = 2 \implies \{b\}$ - $11_2 = 3 \implies \{a, b\}$

3. Quick Cardinality Subsets Breakdown Formula

For a finite set of cardinality $n$: - Total number of subsets: $2^n$ - Total number of proper subsets: $2^n - 1$ - Total number of non-empty subsets: $2^n - 1$ - Total number of non-empty proper subsets: $2^n - 2$ - Number of subsets having at least $k$ elements:

$$ \sum_{r=k}^{n} \binom{n}{r} = 2^n - \sum_{r=0}^{k-1} \binom{n}{r} $$

  • Number of subsets containing a specific fixed element $x$:

$$ 2^{n-1} $$

  • Number of subsets containing $k$ specific fixed elements:

$$ 2^{n-k} $$

  • Number of subsets excluding $k$ specific fixed elements:

$$ 2^{n-k} $$

$$ \big[\max(a, c), \, \min(b, d)\big] $$

(Open becomes closed, closed becomes open). 3. Empty Set Representation:

1.2 Union of Sets ($\cup$) ⭐⭐⭐⭐⭐

  • Formal Set-Builder Definition:
    Let $A$ and $B$ be any two sets. The union of $A$ and $B$ is the set containing all elements that belong either to $A$, or to $B$, or to both.

$$ A \cup B = \{ x \in U : x \in A \lor x \in B \} $$

(Here, the logical connective $\lor$ represents the inclusive OR).

  • Geometric Region:
    The total shaded area covered by circle $A$, circle $B$, and their overlapping region.

  • Algebraic Properties (Laws of Union):

  • Idempotent Law: $A \cup A = A$
  • Commutative Law: $A \cup B = B \cup A$
  • Associative Law: $(A \cup B) \cup C = A \cup (B \cup C)$
  • Identity Law (Law of $\phi$): $A \cup \phi = A$ ($\phi$ is the identity element for union)
  • Domination Law (Law of $U$): $A \cup U = U$
  • Subset Implication: $A \subseteq B \iff A \cup B = B$

1.3 Intersection of Sets ($\cap$) ⭐⭐⭐⭐⭐

  • Formal Set-Builder Definition:
    Let $A$ and $B$ be any two sets. The intersection of $A$ and $B$ is the set consisting of all elements that belong to both $A$ and $B$.

$$ A \cap B = \{ x \in U : x \in A \land x \in B \} $$

(Here, the logical connective $\land$ represents the conjunction AND).

  • Disjoint Sets:
    Two sets $A$ and $B$ are termed mutually disjoint if they share no common elements:

$$ A \cap B = \phi $$

In a Venn diagram, their boundary curves do not overlap.

  • Algebraic Properties (Laws of Intersection):
  • Idempotent Law: $A \cap A = A$
  • Commutative Law: $A \cap B = B \cap A$
  • Associative Law: $(A \cap B) \cap C = A \cap (B \cap C)$
  • Domination Law (Law of $\phi$): $A \cap \phi = \phi$
  • Identity Law (Law of $U$): $A \cap U = A$ ($U$ is the identity element for intersection)

  • Subset Implication: $A \subseteq B \iff A \cap B = A$

  • Distributive Laws of Operations:

  • Intersection distributes over Union:

$$ A \cap (B \cup C) = (A \cap B) \cup (A \cap C) $$

  • Union distributes over Intersection:

$$ A \cup (B \cap C) = (A \cup B) \cap (A \cup C) $$

1.4 Difference of Sets (Relative Complement) ⭐⭐⭐⭐⭐

  • Formal Set-Builder Definition:
    The difference of two sets $A$ and $B$, denoted by $A - B$ (read as "A minus B"), is the set of elements that belong to $A$ but do not belong to $B$.

$$ A - B = \{ x \in U : x \in A \land x \notin B \} $$

Similarly:

$$ B - A = \{ x \in U : x \in B \land x \notin A \} $$

  • Fundamental Properties:
  • Non-Commutative: In general, $A - B \neq B - A$ unless $A = B$.
  • Representation via Complement: $A - B = A \cap B'$, where $B'$ is the absolute complement of $B$.
  • Mutual Disjointness of Canonical Partitions:
    The sets $(A - B)$, $(A \cap B)$, and $(B - A)$ are pairwise mutually disjoint:

$$ (A - B) \cap (A \cap B) = \phi $$

$$ (B - A) \cap (A \cap B) = \phi $$

$$ (A - B) \cap (B - A) = \phi $$

 Furthermore:

$$ A \cup B = (A - B) \cup (A \cap B) \cup (B - A) $$

$$ A = (A - B) \cup (A \cap B) $$

  • Symmetric Difference ($\Delta$) ⭐⭐⭐:
    The set of elements belonging to either $A$ or $B$, but not both:

$$ A \ \Delta \ B = (A - B) \cup (B - A) = (A \cup B) - (A \cap B) $$

2. Complete Step-by-Step Mathematical Proofs & Derivations

Principle of Set Equality

To prove that two sets $X$ and $Y$ are equal ($X = Y$), we must prove mutual inclusion: 1. $X \subseteq Y \iff (\forall x \in X \implies x \in Y)$ 2. $Y \subseteq X \iff (\forall y \in Y \implies y \in X)$ Equivalently, one can construct an unbroken chain of biconditionals ($\iff$).

Theorem 2.1: Distributive Law of Intersection over Union

$$ \text{To Prove: } A \cap (B \cup C) = (A \cap B) \cup (A \cap C) $$

Step 1: Prove $A \cap (B \cup C) \subseteq (A \cap B) \cup (A \cap C)$

Let $x$ be an arbitrary element such that:

$$ x \in A \cap (B \cup C) $$

By definition of intersection:

$$ \implies x \in A \land x \in (B \cup C) $$

By definition of union:

$$ \implies x \in A \land (x \in B \lor x \in C) $$

Applying the logical distributive law of conjunction ($\land$) over disjunction ($\lor$):

$$ \implies (x \in A \land x \in B) \lor (x \in A \land x \in C) $$

Using set-builder definitions of intersection:

$$ \implies x \in (A \cap B) \lor x \in (A \cap C) $$

By definition of union:

$$ \implies x \in (A \cap B) \cup (A \cap C) $$

Since this holds for every $x \in A \cap (B \cup C)$:

$$ A \cap (B \cup C) \subseteq (A \cap B) \cup (A \cap C) \quad \text{--- (Equation 1)} $$

Step 2: Prove $(A \cap B) \cup (A \cap C) \subseteq A \cap (B \cup C)$

Let $y$ be an arbitrary element such that:

$$ y \in (A \cap B) \cup (A \cap C) $$

By definition of union:

$$ \implies y \in (A \cap B) \lor y \in (A \cap C) $$

By definition of intersection:

$$ \implies (y \in A \land y \in B) \lor (y \in A \land y \in C) $$

Factoring out $(y \in A \land)$ by logical distribution:

$$ \implies y \in A \land (y \in B \lor y \in C) $$

By definition of union:

$$ \implies y \in A \land y \in (B \cup C) $$

By definition of intersection:

$$ \implies y \in A \cap (B \cup C) $$

Hence:

$$ (A \cap B) \cup (A \cap C) \subseteq A \cap (B \cup C) \quad \text{--- (Equation 2)} $$

From Equation (1) and Equation (2):

$$ A \cap (B \cup C) = (A \cap B) \cup (A \cap C) \quad \blacksquare $$

Theorem 2.2: Difference Equivalences

$$ \text{To Prove: } A - (B \cup C) = (A - B) \cap (A - C) $$

Let $x$ be an arbitrary element. We apply rigorous logical equivalence:

$$ x \in A - (B \cup C) $$

$$ \iff x \in A \land x \notin (B \cup C) $$

$$ \iff x \in A \land \neg(x \in B \cup C) $$

$$ \iff x \in A \land \neg(x \in B \lor x \in C) $$

By De Morgan's Law of Propositional Logic ($\neg(P \lor Q) \equiv \neg P \land \neg Q$):

$$ \iff x \in A \land (x \notin B \land x \notin C) $$

By Idempotence and Associativity of $\land$, note that $x \in A \equiv (x \in A \land x \in A)$:

$$ \iff (x \in A \land x \notin B) \land (x \in A \land x \notin C) $$

Applying the definition of set difference:

$$ \iff x \in (A - B) \land x \in (A - C) $$

Applying the definition of set intersection:

$$ \iff x \in (A - B) \cap (A - C) $$

Because every step is a reversible biconditional ($\iff$):

$$ A - (B \cup C) = (A - B) \cap (A - C) \quad \blacksquare $$

Theorem 2.3: Fundamental Cardinality Relations for Finite Sets

Let $A$ and $B$ be finite sets.

1. For two sets:

$$ n(A \cup B) = n(A) + n(B) - n(A \cap B) $$

Proof:
Recall that $A \cup B$ can be partitioned into three pairwise disjoint sets:

$$ A \cup B = (A - B) \cup (A \cap B) \cup (B - A) $$

Since they are pairwise disjoint, their cardinalities add directly:

$$ n(A \cup B) = n(A - B) + n(A \cap B) + n(B - A) \quad \text{--- (Eq. I)} $$

Similarly, the set $A$ is the disjoint union of $(A - B)$ and $(A \cap B)$:

$$ A = (A - B) \cup (A \cap B) \implies n(A) = n(A - B) + n(A \cap B) $$

$$ \implies n(A - B) = n(A) - n(A \cap B) \quad \text{--- (Eq. II)} $$

Likewise, for set $B$:

$$ B = (B - A) \cup (A \cap B) \implies n(B) = n(B - A) + n(A \cap B) $$

$$ \implies n(B - A) = n(B) - n(A \cap B) \quad \text{--- (Eq. III)} $$

Substitute (Eq. II) and (Eq. III) into (Eq. I):

$$ n(A \cup B) = [n(A) - n(A \cap B)] + n(A \cap B) + [n(B) - n(A \cap B)] $$

$$ n(A \cup B) = n(A) + n(B) - n(A \cap B) \quad \blacksquare $$

2. For three sets (Inclusion-Exclusion Principle):

$$ n(A \cup B \cup C) = n(A) + n(B) + n(C) - n(A \cap B) - n(B \cap C) - n(C \cap A) + n(A \cap B \cap C) $$

Proof:
Treat $(B \cup C)$ as a single compound set $D$:

$$ n(A \cup (B \cup C)) = n(A \cup D) = n(A) + n(D) - n(A \cap D) $$

$$ = n(A) + n(B \cup C) - n(A \cap (B \cup C)) $$

Substitute $n(B \cup C) = n(B) + n(C) - n(B \cap C)$:

$$ = n(A) + n(B) + n(C) - n(B \cap C) - n(A \cap (B \cup C)) $$

By the Distributive Law, $A \cap (B \cup C) = (A \cap B) \cup (A \cap C)$. Applying the two-set cardinality formula:

$$ n(A \cap (B \cup C)) = n((A \cap B) \cup (A \cap C)) $$

$$ = n(A \cap B) + n(A \cap C) - n((A \cap B) \cap (A \cap C)) $$

$$ = n(A \cap B) + n(C \cap A) - n(A \cap B \cap C) $$

Substitute this back into the main expression:

$$ n(A \cup B \cup C) = n(A) + n(B) + n(C) - n(B \cap C) - [n(A \cap B) + n(C \cap A) - n(A \cap B \cap C)] $$

$$ = n(A) + n(B) + n(C) - n(A \cap B) - n(B \cap C) - n(C \cap A) + n(A \cap B \cap C) \quad \blacksquare $$

Problem 3.3 (Rigorous Theoretical Derivation)

Prove that for any two sets $A$ and $B$:

$$ A \cup B = A \cap B \iff A = B $$

Solution:

Part 1: $(\Longleftarrow)$ Assume $A = B$

$$ A \cup B = A \cup A = A $$

$$ A \cap B = A \cap A = A $$

$$ \implies A \cup B = A \cap B $$

Part 2: $(\Longrightarrow)$ Assume $A \cup B = A \cap B$. To prove $A = B$.
We will prove $A \subseteq B$ and $B \subseteq A$.

  1. Let $x \in A$.

$$ \implies x \in A \cup B \quad (\text{since } A \subseteq A \cup B) $$

Since $A \cup B = A \cap B$:

$$ \implies x \in A \cap B $$

$$ \implies x \in A \land x \in B $$

$$ \implies x \in B $$

Therefore:

$$ A \subseteq B \quad \text{--- (1)} $$

  1. Let $y \in B$.

$$ \implies y \in A \cup B \quad (\text{since } B \subseteq A \cup B) $$

Since $A \cup B = A \cap B$:

$$ \implies y \in A \cap B $$

$$ \implies y \in A \land y \in B $$

$$ \implies y \in A $$

Therefore:

$$ B \subseteq A \quad \text{--- (2)} $$

From (1) and (2), by definition of set equality:

$$ A = B \quad \blacksquare $$

5.2 Golden Cardinality Formulas for Competitive Exams (JEE / Olympiads)

  1. Number of elements in EXACTLY ONE of the sets $A, B, C$:

$$ \sum n(\text{Exactly one}) = [n(A) + n(B) + n(C)] - 2[n(A \cap B) + n(B \cap C) + n(C \cap A)] + 3n(A \cap B \cap C) $$

  1. Number of elements in EXACTLY TWO of the sets $A, B, C$:

$$ \sum n(\text{Exactly two}) = [n(A \cap B) + n(B \cap C) + n(C \cap A)] - 3n(A \cap B \cap C) $$

  1. Number of elements in AT LEAST TWO of the sets $A, B, C$:

$$ \sum n(\text{At least two}) = [n(A \cap B) + n(B \cap C) + n(C \cap A)] - 2n(A \cap B \cap C) $$

Every set identity involving $\cup$ and $\cap$ remains true if: * $\cup$ and $\cap$ are interchanged. * $\phi$ and $U$ are interchanged.

$$ A \cup (A \cap B) = A \quad \xleftrightarrow{\text{Dual}} \quad A \cap (A \cup B) = A \quad (\text{Absorption Laws}) $$

1. Pedagogical Theory & Mathematical Intuition

1.1 The Concept of the Universal Set ($U$) as a Prerequisite

Before defining the complement of a set, a frame of reference must be established. In set theory, this frame of reference is the Universal Set, denoted by $U$ or $\xi$.

Definition: The Universal Set is a set containing all possible objects or elements under consideration for a specific mathematical discussion or context. Any set $A$ under investigation is necessarily a subset of $U$ ($A \subseteq U$).

1.2 Complement of a Set (⭐⭐⭐⭐⭐ Board Priority)

Formal Definition (NCERT):
Let $U$ be the universal set and $A$ be a subset of $U$ ($A \subseteq U$). The complement of $A$ (denoted by $A'$, $A^c$, or $\overline{A}$) is the set of all elements of $U$ which are not elements of $A$.

Set-Builder Notation:

$$ A' = \{x \in U : x \notin A\} $$

Alternatively, in terms of set difference:

$$ A' = U - A $$

Logical Equivalence:

For any element $x \in U$:

$$ x \in A' \iff x \notin A $$

$$ x \notin A' \iff x \in A $$

Geometric Interpretation (Venn Diagram):

In a standard Venn diagram: 1. The universal set $U$ is represented by a closed rectangular region. 2. The set $A$ is represented by a circle or closed curve inside the rectangle. 3. The region inside the rectangle but strictly outside the circle $A$ represents $A'$.

1.3 Properties of Complement of Sets (⭐⭐⭐⭐⭐ Board Priority)

The operation of complementation satisfies several fundamental identities:

  1. Complement Laws:
  2. Union with Complement: $A \cup A' = U$
  3. Intersection with Complement: $A \cap A' = \phi$ (Disjointness)
  4. Law of Double Complementation (Involution Law):
  5. $(A')' = A$
  6. Laws of Empty Set and Universal Set:
  7. $\phi' = U$

2. Complete Step-by-Step Mathematical Proofs & Derivations

In standard board examinations, proofs of set-theoretic identities must be written using the principle of mutual subset inclusion:

$$ \text{To prove } X = Y, \text{ prove } (i)\ X \subseteq Y \quad \text{and} \quad (ii)\ Y \subseteq X. $$

Theorem 1: Complement Laws (⭐⭐⭐⭐)

$$ \text{Statement: For any subset } A \subseteq U, \quad (i)\ A \cup A' = U, \quad (ii)\ A \cap A' = \phi $$

Proof of (i): $A \cup A' = U$

  • Step 1: Let $x$ be an arbitrary element of $A \cup A'$.

$$ x \in A \cup A' \implies x \in A \quad \text{or} \quad x \in A' $$

By definition of $A'$, $x \in A' \implies x \in U \text{ and } x \notin A$.
In either case ($x \in A \subseteq U$ or $x \in A' \subseteq U$), $x \in U$.
Therefore:

$$ A \cup A' \subseteq U \quad \text{--- (1)} $$

  • Step 2: Let $y$ be an arbitrary element of $U$. For any element $y \in U$, by the law of the excluded middle in logic, either $y \in A$ or $y \notin A$.
  • If $y \in A$, then $y \in A \cup A'$.
  • If $y \notin A$, then by definition, $y \in A'$, which also implies $y \in A \cup A'$.
    Hence, in both cases:

$$ y \in A \cup A' \implies U \subseteq A \cup A' \quad \text{--- (2)} $$

  • Conclusion: From (1) and (2), by definition of set equality:

$$ A \cup A' = U \quad \blacksquare $$

Proof of (ii): $A \cap A' = \phi$

  • Proof by Contradiction: Assume $A \cap A' \neq \phi$.
    Then there exists at least one element $x$ such that:

$$ x \in A \cap A' $$

$$ \implies x \in A \quad \text{and} \quad x \in A' $$

Applying the definition of $A'$:

$$ x \in A' \implies x \notin A $$

Hence:

$$ x \in A \quad \text{and} \quad x \notin A $$

This is a logical contradiction ($P \wedge \neg P$).
Therefore, the initial assumption is false.

$$ A \cap A' = \phi \quad \blacksquare $$

Theorem 2: Law of Double Complementation / Involution Law (⭐⭐⭐⭐)

$$ \text{Statement: For any set } A \subseteq U, \quad (A')' = A $$

Proof:

  • Part 1: Show $(A')' \subseteq A$ Let $x \in (A')'$.

$$ \implies x \in U \quad \text{and} \quad x \notin A' $$

Since $x \notin A'$, it is false that ($x \in U$ and $x \notin A$).
Since $x \in U$, it must be true that:

$$ x \in A $$

Therefore:

$$ (A')' \subseteq A \quad \text{--- (1)} $$

  • Part 2: Show $A \subseteq (A')'$ Let $y \in A$.

$$ \implies y \in U \quad \text{and} \quad y \notin A' \quad (\text{since } A' = \{z \in U : z \notin A\}) $$

$$ \implies y \in (A')' \quad (\text{by definition of the complement of } A') $$

Therefore:

$$ A \subseteq (A')' \quad \text{--- (2)} $$

  • Conclusion: From (1) and (2):

$$ (A')' = A \quad \blacksquare $$

Theorem 3: Laws of $\phi$ and $U$ (⭐⭐⭐)

$$ \text{Statement: } (i)\ \phi' = U, \quad (ii)\ U' = \phi $$

Proof of (i):

By definition of complement relative to $U$:

$$ \phi' = U - \phi = \{x \in U : x \notin \phi\} $$

Since the empty set $\phi$ contains no elements, the condition $x \notin \phi$ is vacuously true for all $x \in U$.

$$ \therefore \phi' = U \quad \blacksquare $$

Proof of (ii):

By definition:

$$ U' = U - U = \{x \in U : x \notin U\} $$

There exists no element $x$ in $U$ that satisfies $x \notin U$.

$$ \therefore U' = \phi \quad \blacksquare $$

Theorem 4: De Morgan’s First Law (⭐⭐⭐⭐⭐ Board Priority)

$$ \text{Statement: } (A \cup B)' = A' \cap B' $$

Proof:

  • Part 1: Show $(A \cup B)' \subseteq A' \cap B'$ Let $x$ be an arbitrary element such that:

$$ x \in (A \cup B)' $$

$$ \implies x \notin (A \cup B) $$

$$ \implies \neg (x \in A \cup B) $$

$$ \implies \neg (x \in A \text{ or } x \in B) $$

By logical equivalence ($\neg(P \vee Q) \equiv \neg P \wedge \neg Q$):

$$ \implies (x \notin A) \quad \text{and} \quad (x \notin B) $$

$$ \implies x \in A' \quad \text{and} \quad x \in B' $$

$$ \implies x \in A' \cap B' $$

Since every $x \in (A \cup B)'$ is also in $A' \cap B'$:

$$ (A \cup B)' \subseteq A' \cap B' \quad \text{--- (1)} $$

  • Part 2: Show $A' \cap B' \subseteq (A \cup B)'$ Let $y$ be an arbitrary element such that:

$$ y \in A' \cap B' $$

$$ \implies y \in A' \quad \text{and} \quad y \in B' $$

$$ \implies y \notin A \quad \text{and} \quad y \notin B $$

$$ \implies \neg (y \in A) \quad \text{and} \quad \neg (y \in B) $$

By logical equivalence ($\neg P \wedge \neg Q \equiv \neg(P \vee Q)$):

$$ \implies \neg (y \in A \text{ or } y \in B) $$

$$ \implies y \notin (A \cup B) $$

$$ \implies y \in (A \cup B)' $$

Therefore:

$$ A' \cap B' \subseteq (A \cup B)' \quad \text{--- (2)} $$

  • Conclusion: From (1) and (2):

$$ (A \cup B)' = A' \cap B' \quad \blacksquare $$

Theorem 5: De Morgan’s Second Law (⭐⭐⭐⭐⭐ Board Priority)

$$ \text{Statement: } (A \cap B)' = A' \cup B' $$

Proof:

  • Part 1: Show $(A \cap B)' \subseteq A' \cup B'$ Let $x \in (A \cap B)'$.

$$ \implies x \notin (A \cap B) $$

$$ \implies \neg (x \in A \cap B) $$

$$ \implies \neg (x \in A \text{ and } x \in B) $$

By logical equivalence ($\neg(P \wedge Q) \equiv \neg P \vee \neg Q$):

$$ \implies (x \notin A) \quad \text{or} \quad (x \notin B) $$

$$ \implies x \in A' \quad \text{or} \quad x \in B' $$

$$ \implies x \in A' \cup B' $$

Therefore:

$$ (A \cap B)' \subseteq A' \cup B' \quad \text{--- (1)} $$

  • Part 2: Show $A' \cup B' \subseteq (A \cap B)'$ Let $y \in A' \cup B'$.

$$ \implies y \in A' \quad \text{or} \quad y \in B' $$

$$ \implies y \notin A \quad \text{or} \quad y \notin B $$

$$ \implies \neg (y \in A) \quad \text{or} \quad \neg (y \in B) $$

By logical equivalence:

$$ \implies \neg (y \in A \text{ and } y \in B) $$

$$ \implies y \notin (A \cap B) $$

$$ \implies y \in (A \cap B)' $$

Therefore:

$$ A' \cup B' \subseteq (A \cap B)' \quad \text{--- (2)} $$

  • Conclusion: From (1) and (2):

$$ (A \cap B)' = A' \cup B' \quad \blacksquare $$

Problem 1: Numerical Verification of De Morgan's Laws (Board 3-Marker)

Question: Let $U = \{1, 2, 3, 4, 5, 6, 7, 8, 9\}$, $A = \{2, 4, 6, 8\}$, and $B = \{2, 3, 5, 7\}$.
Verify that $(A \cup B)' = A' \cap B'$.

Solution:

[Scoring: 0.5 Mark]

$$ \therefore \text{L.H.S.} = \{1, 9\} \quad \text{--- (1)} $$

Problem 2: NCERT Exemplar — Algebraic Proof with Complement

Question: For any two sets $A$ and $B$, prove using properties that:

$$ A - B = A \cap B' $$

Solution:

  • Part 1: Prove $A - B \subseteq A \cap B'$ Let $x \in A - B$.

$$ \implies x \in A \quad \text{and} \quad x \notin B $$

Since $x \notin B$, by definition of complement, $x \in B'$.

$$ \implies x \in A \quad \text{and} \quad x \in B' $$

$$ \implies x \in A \cap B' $$

$$ \therefore A - B \subseteq A \cap B' \quad \text{--- (1)} $$

  • Part 2: Prove $A \cap B' \subseteq A - B$ Let $y \in A \cap B'$.

$$ \implies y \in A \quad \text{and} \quad y \in B' $$

Since $y \in B'$, $y \notin B$.

$$ \implies y \in A \quad \text{and} \quad y \notin B $$

$$ \implies y \in A - B $$

$$ \therefore A \cap B' \subseteq A - B \quad \text{--- (2)} $$

  • Conclusion: From (1) and (2):

$$ A - B = A \cap B' \quad \blacksquare $$

Problem 3: Advanced Set Simplification (JEE Main / High-Order Exemplar)

Question: Simplify the following set expression using set-algebra identities:

$$ E = (A \cup B) \cap (A \cup B') $$

Solution:

  • Step 1: Apply Distributive Law of $\cup$ over $\cap$ in reverse
    Recall: $X \cup (Y \cap Z) = (X \cup Y) \cap (X \cup Z)$.
    Here, taking $X = A$, $Y = B$, $Z = B'$:

$$ (A \cup B) \cap (A \cup B') = A \cup (B \cap B') $$

  • Step 2: Apply Complement Law
    We know $B \cap B' = \phi$. Substituting this into the expression:

$$ E = A \cup \phi $$

  • Step 3: Apply Identity Law
    For any set $A$, $A \cup \phi = A$.

$$ \therefore (A \cup B) \cap (A \cup B') = A $$

Problem 4: Cardinality Relation Involving Complement (Exemplar Application)

Question: Let $U$ be a universal set of 700 students. $A$ is the set of students who study Mathematics, $B$ is the set of students who study Physics. Given $n(U) = 700$, $n(A) = 300$, $n(B) = 250$, and $n(A \cap B) = 100$.
Find the number of students who study neither Mathematics nor Physics.

Solution:

  • Step 1: Formulate the required set in notation
    "Neither Mathematics nor Physics" corresponds to $A' \cap B'$.

  • Step 2: Apply De Morgan's Law

$$ A' \cap B' = (A \cup B)' $$

  • Step 3: Use the Cardinality of Complement Formula

$$ n((A \cup B)') = n(U) - n(A \cup B) $$

$$ n(A \cup B) = n(A) + n(B) - n(A \cap B) $$

$$ n(A \cup B) = 300 + 250 - 100 = 450 $$

  • Step 5: Compute Final Value

$$ n(A' \cap B') = 700 - 450 = 250 $$

5. Speed Hacks & Golden Points

5.1 The De Morgan "Flip & Invert" Rule

Whenever a complement bar is distributed over parentheses: 1. Complement every individual set term. 2. Invert the operator: - $\cup \longrightarrow \cap$ - $\cap \longrightarrow \cup$

$$ \overline{(A \cup B \cup C \dots)} = \overline{A} \cap \overline{B} \cap \overline{C} \dots $$

$$ \overline{(A \cap B \cap C \dots)} = \overline{A} \cup \overline{B} \cup \overline{C} \dots $$

5.2 Cardinality Quick Formulas (Golden Formulas)

For finite universal sets: - $n(A') = n(U) - n(A)$ - $n(A \cap B') = n(A - B) = n(A) - n(A \cap B)$ - $n(A' \cap B') = n((A \cup B)') = n(U) - n(A \cup B)$ - $n(A' \cup B') = n((A \cap B)') = n(U) - n(A \cap B)$

5.3 Boolean / Binary Trick for Competitive Exams (JEE Main)

Convert sets into binary logic states ($1$ and $0$): - Set presence $\in A \equiv 1$ - Set absence $\notin A \equiv 0$ - Complement $A' \equiv 1 - A$ - Intersection $A \cap B \equiv A \cdot B$ - Union $A \cup B \equiv A + B - A \cdot B$

Instant Verification of $(A \cup B)' = A' \cap B'$:

  • $\text{L.H.S.: } 1 - (A + B - AB)$
  • $\text{R.H.S.: } (1 - A)(1 - B) = 1 - A - B + AB = 1 - (A + B - AB)$
  • $\text{L.H.S.} = \text{R.H.S.}$ in 5 seconds.

Module 1: Foundational Theory & Mathematical Intuition

1.1 Definition of Cardinality (Star Priority: ⭐⭐⭐)

Let $A$ be a finite set. The cardinality or cardinal number of set $A$, denoted by $n(A)$ or $|A|$ (NCERT standard notation: $n(A)$), is defined as the total number of distinct elements contained in $A$.

  • Axiom of the Empty Set: For the null set $\phi$, $n(\phi) = 0$.
  • Finite vs. Infinite: If the counting process of distinct elements terminates at a natural number $k \in \mathbb{N}$, then $A$ is finite and $n(A) = k$. Otherwise, $A$ is an infinite set.

1.2 The Principle of Disjoint Additivity (Star Priority: ⭐⭐⭐⭐)

Two sets $A$ and $B$ are defined as mutually disjoint (or pairwise disjoint) if and only if:

$$ A \cap B = \phi $$

Fundamental Cardinality Postulate: If $A$ and $B$ are finite disjoint sets, then:

$$ n(A \cup B) = n(A) + n(B) $$

Geometric & Set-Theoretic Intuition:

When $A \cap B = \phi$, the sets share zero boundary and zero common space inside the universal set $U$. Every element belongs exclusively to either $A$ or $B$. Therefore, counting the elements of the combined set $A \cup B$ is strictly additive.

1.3 Decomposition into Pairwise Disjoint Canonical Subsets (Star Priority: ⭐⭐⭐⭐⭐)

For any two arbitrary finite sets $A$ and $B$, the set $A \cup B$ can be uniquely partitioned into three mutually disjoint subsets: 1. Only $A$ (Set difference $A - B$, or $A \cap B'$) 2. Both $A$ and $B$ (Intersection $A \cap B$) 3. Only $B$ (Set difference $B - A$, or $B \cap A'$)

+-------------------------------------------------------+
| Universal Set U                                       |
|      +-------------------+   +-------------------+    |
|     /    Only A           \ /           Only B    \   |
|    /     (A - B)    +------X------+     (B - A)    \  |
|   |                 | A ∩ B       |                 | |
|    \                +------X------+                /  |
|     \                     / \                     /   |
|      +-------------------+   +-------------------+    |
|                                                       |
|   Neither A nor B: (A ∪ B)' = U - (A ∪ B)             |
+-------------------------------------------------------+

From this canonical partition:

$$ A = (A - B) \cup (A \cap B) \quad \text{where } (A - B) \cap (A \cap B) = \phi $$

$$ B = (B - A) \cup (A \cap B) \quad \text{where } (B - A) \cap (A \cap B) = \phi $$

$$ A \cup B = (A - B) \cup (A \cap B) \cup (B - A) \quad \text{where all three are pairwise disjoint} $$

Module 2: Complete Mathematical Proofs & Derivations

Theorem 1: Cardinality of the Union of Two Arbitrary Sets (Star Priority: ⭐⭐⭐⭐⭐)

For any two finite sets $A$ and $B$:

$$ n(A \cup B) = n(A) + n(B) - n(A \cap B) $$

Proof:

  • Given: $A$ and $B$ are two finite sets with cardinalities $n(A)$, $n(B)$, and $n(A \cap B)$.
  • To Prove: $n(A \cup B) = n(A) + n(B) - n(A \cap B)$
  • Derivation:

Step 1: Express $A \cup B$ as the union of two disjoint sets:

$$ A \cup B = (A - B) \cup B $$

Notice that:

$$ (A - B) \cap B = (A \cap B') \cap B = A \cap (B' \cap B) = A \cap \phi = \phi $$

Since $(A - B)$ and $B$ are disjoint, apply the disjoint additivity property:

$$ n(A \cup B) = n(A - B) + n(B) \quad \text{--- (Equation 1)} $$

Step 2: Express $A$ as the union of two disjoint sets:

$$ A = (A - B) \cup (A \cap B) $$

Verify disjointness:

$$ (A - B) \cap (A \cap B) = (A \cap B') \cap (A \cap B) = A \cap (B' \cap B) = \phi $$

Therefore:

$$ n(A) = n(A - B) + n(A \cap B) $$

Rearranging gives:

$$ n(A - B) = n(A) - n(A \cap B) \quad \text{--- (Equation 2)} $$

Step 3: Substitute Equation 2 into Equation 1:

$$ n(A \cup B) = [n(A) - n(A \cap B)] + n(B) $$

$$ n(A \cup B) = n(A) + n(B) - n(A \cap B) $$

$$ \tag*{Q.E.D.} $$

Theorem 2: Cardinality of Exactly One Set (Two Sets) (Star Priority: ⭐⭐⭐⭐)

The number of elements that belong to exactly one of the sets $A$ or $B$ (also called the symmetric difference $A \ \Delta \ B$) is:

$$ n(A \ \Delta \ B) = n(A - B) + n(B - A) = n(A) + n(B) - 2n(A \cap B) = n(A \cup B) - n(A \cap B) $$

Proof:

  • Given: Sets $A$ and $B$.
  • To Prove: $n(\text{exactly one of } A, B) = n(A) + n(B) - 2n(A \cap B)$
  • Derivation:

Step 1: The set of elements belonging to exactly one of $A$ or $B$ is:

$$ (A - B) \cup (B - A) $$

Since $(A - B) \cap (B - A) = \phi$:

$$ n(\text{exactly one}) = n(A - B) + n(B - A) $$

Step 2: Substitute $n(A - B) = n(A) - n(A \cap B)$ and $n(B - A) = n(B) - n(A \cap B)$:

$$ n(\text{exactly one}) = [n(A) - n(A \cap B)] + [n(B) - n(A \cap B)] $$

$$ n(\text{exactly one}) = n(A) + n(B) - 2n(A \cap B) $$

Step 3: Relate to the union:

$$ n(A) + n(B) - n(A \cap B) - n(A \cap B) = n(A \cup B) - n(A \cap B) $$

$$ \tag*{Q.E.D.} $$

Theorem 3: Cardinality of the Union of Three Sets (Inclusion-Exclusion Principle) (Star Priority: ⭐⭐⭐⭐⭐)

For any three finite sets $A$, $B$, and $C$:

$$ n(A \cup B \cup C) = n(A) + n(B) + n(C) - n(A \cap B) - n(B \cap C) - n(C \cap A) + n(A \cap B \cap C) $$

Proof:

  • Given: $A, B, C$ are finite sets.
  • To Prove: $n(A \cup B \cup C) = \sum n(A) - \sum n(A \cap B) + n(A \cap B \cap C)$
  • Derivation:

Step 1: Let $D = B \cup C$. Then:

$$ A \cup B \cup C = A \cup (B \cup C) = A \cup D $$

Step 2: By Theorem 1:

$$ n(A \cup D) = n(A) + n(D) - n(A \cap D) \quad \text{--- (Equation 3)} $$

Step 3: Expand $n(D)$:

$$ n(D) = n(B \cup C) = n(B) + n(C) - n(B \cap C) \quad \text{--- (Equation 4)} $$

Step 4: Expand $n(A \cap D)$ using the distributive law of intersection over union:

$$ A \cap D = A \cap (B \cup C) = (A \cap B) \cup (A \cap C) $$

Let $X = A \cap B$ and $Y = A \cap C$. By Theorem 1:

$$ n(X \cup Y) = n(X) + n(Y) - n(X \cap Y) $$

Notice that:

$$ X \cap Y = (A \cap B) \cap (A \cap C) = A \cap A \cap B \cap C = A \cap B \cap C $$

Therefore:

$$ n(A \cap D) = n(A \cap B) + n(A \cap C) - n(A \cap B \cap C) \quad \text{--- (Equation 5)} $$

Step 5: Substitute Equations 4 and 5 into Equation 3:

$$ n(A \cup B \cup C) = n(A) + [n(B) + n(C) - n(B \cap C)] - [n(A \cap B) + n(A \cap C) - n(A \cap B \cap C)] $$

Distribute the negative sign:

$$ n(A \cup B \cup C) = n(A) + n(B) + n(C) - n(A \cap B) - n(B \cap C) - n(C \cap A) + n(A \cap B \cap C) $$

$$ \tag*{Q.E.D.} $$

Theorem 4: Cardinality of Exactly Two Sets & Exactly One Set (Three Sets) (Star Priority: ⭐⭐⭐⭐)

1. Number of elements belonging to EXACTLY TWO of sets $A, B, C$:

$$ n(\text{Exactly Two}) = n(A \cap B) + n(B \cap C) + n(C \cap A) - 3n(A \cap B \cap C) $$

  • Proof: In the sum $n(A \cap B) + n(B \cap C) + n(C \cap A)$, elements in:
  • Exactly two sets are counted once (e.g., an element in $A \cap B$ only is in $A \cap B$, but not in $B \cap C$ or $C \cap A$).
  • All three sets $(A \cap B \cap C)$ are counted in every one of the three pairwise intersections ($1 + 1 + 1 = 3$ times). To count only elements in exactly two sets, we must subtract the 3-set intersection 3 times:

$$ n(\text{Exactly Two}) = [n(A \cap B) - n(A \cap B \cap C)] + [n(B \cap C) - n(A \cap B \cap C)] + [n(C \cap A) - n(A \cap B \cap C)] $$

$$ = n(A \cap B) + n(B \cap C) + n(C \cap A) - 3n(A \cap B \cap C) $$

$$ \tag*{Q.E.D.} $$

2. Number of elements belonging to AT LEAST TWO of sets $A, B, C$:

$$ n(\text{At Least Two}) = n(A \cap B) + n(B \cap C) + n(C \cap A) - 2n(A \cap B \cap C) $$

3. Number of elements belonging to EXACTLY ONE of sets $A, B, C$:

$$ n(\text{Exactly One}) = n(A) + n(B) + n(C) - 2[n(A \cap B) + n(B \cap C) + n(C \cap A)] + 3n(A \cap B \cap C) $$

  • Proof via Partition Method: Let the regions of the 3-circle Venn Diagram be labeled:
  • $a, b, c$: elements in only $A$, only $B$, only $C$
  • $d, e, f$: elements in only $(A \cap B)$, only $(B \cap C)$, only $(C \cap A)$
  • $g$: elements in $A \cap B \cap C$

We want to find $a + b + c$:

$$ \sum n(A) = (a + d + f + g) + (b + d + e + g) + (c + e + f + g) = (a + b + c) + 2(d + e + f) + 3g $$

$$ \sum n(A \cap B) = (d + g) + (e + g) + (f + g) = (d + e + f) + 3g $$

Multiply $\sum n(A \cap B)$ by 2:

$$ 2\sum n(A \cap B) = 2(d + e + f) + 6g $$

Now subtract this from $\sum n(A)$:

$$ \sum n(A) - 2\sum n(A \cap B) = [(a + b + c) + 2(d + e + f) + 3g] - [2(d + e + f) + 6g] = (a + b + c) - 3g $$

Add $3g = 3n(A \cap B \cap C)$ to isolate $(a + b + c)$:

$$ a + b + c = \sum n(A) - 2\sum n(A \cap B) + 3n(A \cap B \cap C) $$

$$ \tag*{Q.E.D.} $$

Problem 1: Two-Variable Survey Problem (NCERT Standard)

Problem Statement: In a school survey of 400 students, 100 were listed as taking apple juice, 150 as taking orange juice, and 75 were listed as taking both apple as well as orange juice. Find how many students were taking neither apple juice nor orange juice.

Model Solution & Marking Scheme:

  • Step 1: Define Sets & Identify Given Data [1 Mark] Let $U$ be the universal set of students surveyed. Let $A$ be the set of students taking apple juice. Let $B$ be the set of students taking orange juice.

$$ n(U) = 400 $$

$$ n(A) = 100 $$

$$ n(B) = 150 $$

$$ n(A \cap B) = 75 $$

  • Step 2: Find $n(A \cup B)$ using Cardinality Formula [1.5 Marks]

$$ n(A \cup B) = n(A) + n(B) - n(A \cap B) $$

$$ n(A \cup B) = 100 + 150 - 75 = 250 - 75 = 175 $$

  • Step 3: Apply De Morgan's Law for Neither $A$ nor $B$ [1.5 Marks] The set of students taking neither apple juice nor orange juice is $A' \cap B'$. By De Morgan's Law:

$$ A' \cap B' = (A \cup B)' $$

Therefore:

$$ n(A' \cap B') = n(U) - n(A \cup B) $$

$$ n(A' \cap B') = 400 - 175 = 225 $$

Problem 2: Three-Variable Newspaper Problem (NCERT Exemplar / Board Favorite)

Problem Statement: In a survey of 60 people, it was found that 25 people read newspaper $H$, 26 read newspaper $T$, 26 read newspaper $I$, 9 read both $H$ and $I$, 11 read both $H$ and $T$, 8 read both $T$ and $I$, and 3 read all three newspapers. Find: 1. The number of people who read at least one of the newspapers. 2. The number of people who read exactly one newspaper.

Model Solution & Marking Scheme:

  • Step 1: Set Designation and Given Data [1 Mark] Let $H, T, I$ denote the sets of people reading newspapers $H$, $T$, and $I$ respectively.

$$ n(U) = 60 $$

$$ n(H) = 25, \quad n(T) = 26, \quad n(I) = 26 $$

$$ n(H \cap T) = 11, \quad n(H \cap I) = 9, \quad n(T \cap I) = 8 $$

$$ n(H \cap T \cap I) = 3 $$

  • Step 2: Part (1) — At least one newspaper [2 Marks]

$$ n(H \cup T \cup I) = n(H) + n(T) + n(I) - n(H \cap T) - n(H \cap I) - n(T \cap I) + n(H \cap T \cap I) $$

$$ n(H \cup T \cup I) = 25 + 26 + 26 - 11 - 9 - 8 + 3 $$

$$ n(H \cup T \cup I) = 77 - 28 + 3 = 52 $$

Answer (1): 52 people read at least one newspaper.

  • Step 3: Part (2) — Exactly one newspaper [2 Marks] Method A (Direct Formula):

$$ n(\text{Exactly One}) = \sum n(H) - 2\sum n(H \cap T) + 3n(H \cap T \cap I) $$

$$ n(\text{Exactly One}) = (25 + 26 + 26) - 2(11 + 9 + 8) + 3(3) $$

$$ n(\text{Exactly One}) = 77 - 2(28) + 9 = 77 - 56 + 9 = 30 $$

Method B (Verification via Region Filling): * Center region: $g = n(H \cap T \cap I) = 3$ * $H \cap T \text{ only}: 11 - 3 = 8$ * $H \cap I \text{ only}: 9 - 3 = 6$ * $T \cap I \text{ only}: 8 - 3 = 5$ * $H \text{ only}: 25 - (8 + 6 + 3) = 25 - 17 = 8$ * $T \text{ only}: 26 - (8 + 5 + 3) = 26 - 16 = 10$ * $I \text{ only}: 26 - (6 + 5 + 3) = 26 - 14 = 12$

$$ \text{Sum of exactly one} = 8 + 10 + 12 = 30 $$

Answer (2): 30 people read exactly one newspaper.

Problem 3: Advanced Consistency & Bounded Cardinality Problem

Problem Statement: A market research agency claims that in a town of 10,000 families, $70\%$ families buy brand $A$, $60\%$ buy brand $B$, and $45\%$ buy brand $C$. Also, $35\%$ buy $A$ and $B$, $25\%$ buy $B$ and $C$, and $30\%$ buy $A$ and $C$. If $15\%$ buy all three brands, examine the statistical consistency of this report.

Model Solution:

  • Let total percentage $n(U) = 100\%$.
  • Given:

$$ n(A) = 70, \quad n(B) = 60, \quad n(C) = 45 $$

$$ n(A \cap B) = 35, \quad n(B \cap C) = 25, \quad n(A \cap C) = 30 $$

$$ n(A \cap B \cap C) = 15 $$

  • Calculate $n(A \cup B \cup C)$:

$$ n(A \cup B \cup C) = \sum n(A) - \sum n(A \cap B) + n(A \cap B \cap C) $$

$$ n(A \cup B \cup C) = (70 + 60 + 45) - (35 + 25 + 30) + 15 $$

$$ n(A \cup B \cup C) = 175 - 90 + 15 = 100\% $$

  • Now check individual non-overlapping regions:

$$ \text{Only } B = n(B) - [n(A \cap B \text{ only}) + n(B \cap C \text{ only}) + n(A \cap B \cap C)] $$

  • $n(A \cap B \cap C) = 15$
  • $n(A \cap B \text{ only}) = 35 - 15 = 20$
  • $n(B \cap C \text{ only}) = 25 - 15 = 10$

$$ \text{Only } B = 60 - [20 + 10 + 15] = 60 - 45 = 15\% \ge 0 \quad (\text{Valid}) $$

  • Check Only $A$:
  • $n(A \cap C \text{ only}) = 30 - 15 = 15$

$$ \text{Only } A = 70 - [20 + 15 + 15] = 70 - 50 = 20\% \ge 0 \quad (\text{Valid}) $$

  • Check Only $C$:

$$ \text{Only } C = 45 - [15 + 10 + 15] = 45 - 40 = 5\% \ge 0 \quad (\text{Valid}) $$

  • Conclusion: Since $n(A \cup B \cup C) \le 100\%$ and all 8 mutually exclusive regions are non-negative, the agency's report is consistent and valid.

Module 4: Examiner Traps & Common Student Pitfalls

Trap Number Common Mistake Why It Fails Mathematically Correct Method
Trap 1 Equating $n(U)$ with $n(A \cup B)$ Assumes every surveyed person must like at least one item. Ignores $(A \cup B)'$. Treat $n(U) \ge n(A \cup B)$. Only equate them if the problem states "each person likes at least one item".
Trap 2 Direct Subtraction in Venn Diagrams Writing $n(A \cap B)$ directly into the 2-set intersection region of a 3-set problem. Must subtract the central intersection first: $\text{Region} = n(A \cap B) - n(A \cap B \cap C)$.
Trap 3 Sign Error in Inclusion-Exclusion Writing $-\ n(A \cap B \cap C)$ at the end of the 3-set formula. The 3-way intersection is subtracted 3 times during pairwise subtractions; it must be added back (+) to balance the count.
Trap 4 Confusing "Neither" with "Not Both" Treating "Neither $A$ nor $B$" as $A' \cup B'$. "Neither $A$ nor $B$" is $A' \cap B' = (A \cup B)'$.
"Not both" is $(A \cap B)' = A' \cup B'$.
Trap 5 Violating Non-Negativity Forgetting that cardinality cannot be negative ($n(X) \ge 0$). In bounded variables or consistency questions, every individual region $a, b, c, d, e, f, g \ge 0$.

Module 5: Speed Hacks, Golden Points & Mnemonics

5.1 The Region Sum Rule for 3 Sets

Let the 8 disjoint regions be: * $S_1 = a + b + c$ (Elements in exactly 1 set) * $S_2 = d + e + f$ (Elements in exactly 2 sets) * $S_3 = g$ (Elements in all 3 sets) * $S_0 = \text{Elements in none of the sets}$

Then:

$$ \sum n(A) = S_1 + 2S_2 + 3S_3 $$

$$ \sum n(A \cap B) = S_2 + 3S_3 $$

$$ n(A \cap B \cap C) = S_3 $$

$$ n(A \cup B \cup C) = S_1 + S_2 + S_3 $$

Quick Mental Formula for $S_1$ (Exactly One):

$$ S_1 = \sum n(A) - 2\sum n(A \cap B) + 3n(A \cap B \cap C) $$

Quick Mental Formula for $S_2$ (Exactly Two):

$$ S_2 = \sum n(A \cap B) - 3n(A \cap B \cap C) $$

5.2 Mnemonic for Inclusion-Exclusion: A-S-A (Add-Subtract-Add)

$$ \text{Union} = \mathbf{\text{ADD}} \text{ singles} \longrightarrow \mathbf{\text{SUBTRACT}} \text{ pairs} \longrightarrow \mathbf{\text{ADD}} \text{ triples} $$

5.3 Inequality Bounds on Intersection

For any two finite sets $A$ and $B$ in universal set $U$:

$$ \max(0, \, n(A) + n(B) - n(U)) \le n(A \cap B) \le \min(n(A), \, n(B)) $$

  • Lower Bound Logic: Since $n(A \cup B) \le n(U)$, we have $n(A) + n(B) - n(A \cap B) \le n(U) \implies n(A \cap B) \ge n(A) + n(B) - n(U)$.
  • Upper Bound Logic: $A \cap B \subseteq A$ and $A \cap B \subseteq B$, so $n(A \cap B)$ cannot exceed the smaller set.

Example Check: If $n(U) = 100$, $n(A) = 70$, $n(B) = 60$:

$$ \max(0, 70 + 60 - 100) \le n(A \cap B) \le \min(70, 60) $$

$$ 30 \le n(A \cap B) \le 60 $$

Model Solution & Marking Rubric: * Evaluation of Assertion:

$$ \phi \implies n(\phi) = 0 $$

$$ P(\phi) \implies 2^0 = 1 \text{ element (namely } \{\phi\}\text{)} $$

$$ P(P(\phi)) \implies 2^1 = 2 \text{ elements (namely } \{\phi, \{\phi\}\}\text{)} $$

$$ P(P(P(\phi))) \implies 2^2 = 4 \text{ elements.} $$

Hence, Assertion (A) is True. * Evaluation of Reason: The standard theorem states that if $|S| = n$, then $|P(S)| = 2^n$. Hence, Reason (R) is True. * Relation: Reason (R) is applied recursively three times to yield $2^{2^{2^0}} = 4$. Thus, (R) is the correct explanation of (A). * Correct Option: (a)

$$ \text{[Full Credit: } \mathbf{1\text{ Mark}}\text{]} $$

Item A3.2: Intervals vs Discrete Sets

  • Assertion (A): The set $A = \{x \in \mathbb{R} : x^2 + 1 = 0\}$ is a non-empty finite set.
  • Reason (R): An empty set $\phi$ has no elements, and its cardinal number is $0$.

Model Solution & Marking Rubric: * Evaluation of Assertion:

$$ x^2 + 1 = 0 \implies x^2 = -1 $$

For any real number $x \in \mathbb{R}$, $x^2 \ge 0$, so $x^2 + 1 \ge 1 > 0$. There exists no real number $x$ satisfying this equation. Thus, $A = \phi$ (empty set). $$ \text{[Full Credit: } \mathbf{1\text{ Mark}}\text{]} $$

Item A3.3: Set Difference and Symmetric Difference

  • Assertion (A): For any two sets $A$ and $B$, $(A \setminus B) \cup (B \setminus A) = (A \cup B) \setminus (A \cap B)$.
  • Reason (R): $A \setminus B = A \cap B'$.

$$ = [(A \cap B') \cup B] \cap [(A \cap B') \cup A'] $$

Question B1: Rigorous Proof of Set Distributive Law

Tag: <span class="step-mark-tag">[NCERT Miscellaneous Exercise, Q8 / Theory Proof, 4 Marks]</span>

Problem Statement:

Using formal set-theoretic definitions and element-wise containment arguments, prove that for any three sets $A, B$, and $C$:

$$ A \cap (B \cup C) = (A \cap B) \cup (A \cap C) $$

📝 View CBSE Model Solution & Step-Marking Scheme ▼

Model Solution & CBSE Step-Marking Rubric:

To establish equality between two sets $X$ and $Y$, we must prove mutual subset containment: $X \subseteq Y$ and $Y \subseteq X$.

Step 1: To prove $A \cap (B \cup C) \subseteq (A \cap B) \cup (A \cap C)$ * Let $x$ be an arbitrary element such that:

$$ x \in A \cap (B \cup C) $$

  • By definition of set intersection:

$$ x \in A \quad \text{and} \quad x \in (B \cup C) $$

$$ \text{[Step Definition: } \mathbf{\tfrac{1}{2}\text{ Mark}}\text{]} $$

  • By definition of union:

$$ x \in A \quad \text{and} \quad (x \in B \text{ or } x \in C) $$

  • Using logical distributivity:

$$ (x \in A \text{ and } x \in B) \quad \text{or} \quad (x \in A \text{ and } x \in C) $$

$$ \text{[Logical Distribution step: } \mathbf{1\text{ Mark}}\text{]} $$

  • Translating back to set notation:

$$ x \in (A \cap B) \quad \text{or} \quad x \in (A \cap C) $$

$$ \implies x \in (A \cap B) \cup (A \cap C) $$

  • Since every element of $A \cap (B \cup C)$ is in $(A \cap B) \cup (A \cap C)$:

$$ A \cap (B \cup C) \subseteq (A \cap B) \cup (A \cap C) \quad \text{--- (Equation 1)} $$

$$ \text{[Containment conclusion: } \mathbf{\tfrac{1}{2}\text{ Mark}}\text{]} $$

Step 2: To prove $(A \cap B) \cup (A \cap C) \subseteq A \cap (B \cup C)$ * Let $y$ be an arbitrary element such that:

$$ y \in (A \cap B) \cup (A \cap C) $$

  • By definition of set union:

$$ y \in (A \cap B) \quad \text{or} \quad y \in (A \cap C) $$

$$ \text{[Step Definition: } \mathbf{\tfrac{1}{2}\text{ Mark}}\text{]} $$

  • Expanding both conjunctions:

$$ (y \in A \text{ and } y \in B) \quad \text{or} \quad (y \in A \text{ and } y \in C) $$

  • By the distributive property of logical propositions:

$$ y \in A \quad \text{and} \quad (y \in B \text{ or } y \in C) $$

$$ \text{[Logical step: } \mathbf{1\text{ Mark}}\text{]} $$

  • Expressing in set operations:

$$ y \in A \quad \text{and} \quad y \in (B \cup C) $$

$$ \implies y \in A \cap (B \cup C) $$

  • Hence:

$$ (A \cap B) \cup (A \cap C) \subseteq A \cap (B \cup C) \quad \text{--- (Equation 2)} $$

$$ \text{[Containment conclusion: } \mathbf{\tfrac{1}{2}\text{ Mark}}\text{]} $$

Conclusion: From (1) and (2), by definition of set equality:

$$ A \cap (B \cup C) = (A \cap B) \cup (A \cap C) $$

Hence proved.

Question C1: Multi-Set Multiplicity and Divisibility

Tag: <span class="step-mark-tag">[NCERT Exemplar, Long Answer, 5 Marks]</span>
Priority: ⭐⭐⭐⭐⭐ [Must-Know]

Problem Statement:

Let $\mathbb{N}$ denote the set of all positive integers. For each $k \in \mathbb{N}$, define:

$$ k\mathbb{N} = \{kx : x \in \mathbb{N}\} $$

  1. Describe the set $3\mathbb{N} \cap 7\mathbb{N}$. (1 Mark)
  2. In general, if $a, b \in \mathbb{N}$, determine the set $a\mathbb{N} \cap b\mathbb{N}$ in terms of the number-theoretic properties of $a$ and $b$. Prove the result rigorously. (2 Marks)
  3. Find the set $(6\mathbb{N} \cap 8\mathbb{N}) \cap 12\mathbb{N}$. (2 Marks)
📝 View CBSE Model Solution & Step-Marking Scheme ▼

Model Solution & CBSE Step-Marking Rubric:

Part (1): Evaluating $3\mathbb{N} \cap 7\mathbb{N}$ * $3\mathbb{N} = \{3, 6, 9, 12, 15, 18, 21, 24, \dots\}$ * $7\mathbb{N} = \{7, 14, 21, 28, \dots\}$ * An integer $x \in 3\mathbb{N} \cap 7\mathbb{N} \iff 3 \mid x$ and $7 \mid x$. * Since $\gcd(3, 7) = 1$, $x$ is divisible by $\text{LCM}(3, 7) = 21$.

$$ 3\mathbb{N} \cap 7\mathbb{N} = 21\mathbb{N} $$

$$ \text{[Correct Set Identification: } \mathbf{1\text{ Mark}}\text{]} $$

Part (2): General Theorem for $a\mathbb{N} \cap b\mathbb{N}$ * Statement: $a\mathbb{N} \cap b\mathbb{N} = d\mathbb{N}$, where $d = \text{LCM}(a, b)$. * Rigorous Proof: - Let $x \in a\mathbb{N} \cap b\mathbb{N}$.

$$ \implies x \in a\mathbb{N} \implies a \mid x $$

$$ \implies x \in b\mathbb{N} \implies b \mid x $$

  • By definition of least common multiple, if an integer is a multiple of both $a$ and $b$, it must be a multiple of $\text{LCM}(a, b)$.

$$ \implies \text{LCM}(a, b) \mid x \implies x \in (\text{LCM}(a, b))\mathbb{N} $$

$$ \text{Hence, } a\mathbb{N} \cap b\mathbb{N} \subseteq (\text{LCM}(a, b))\mathbb{N} \quad \text{--- (1)} $$

$$ \text{[Forward containment proof: } \mathbf{1\text{ Mark}}\text{]} $$

  • Conversely, let $y \in (\text{LCM}(a, b))\mathbb{N}$. Then $y = k \cdot \text{LCM}(a, b)$ for some $k \in \mathbb{N}$. Since $a \mid \text{LCM}(a, b)$ and $b \mid \text{LCM}(a, b)$, we have $a \mid y$ and $b \mid y$.

$$ \implies y \in a\mathbb{N} \quad \text{and} \quad y \in b\mathbb{N} \implies y \in a\mathbb{N} \cap b\mathbb{N} $$

$$ \text{Hence, } (\text{LCM}(a, b))\mathbb{N} \subseteq a\mathbb{N} \cap b\mathbb{N} \quad \text{--- (2)} $$

  • From (1) and (2):

$$ a\mathbb{N} \cap b\mathbb{N} = (\text{LCM}(a, b))\mathbb{N} $$

$$ \text{[Reverse containment & conclusion: } \mathbf{1\text{ Mark}}\text{]} $$

Part (3): Evaluating $(6\mathbb{N} \cap 8\mathbb{N}) \cap 12\mathbb{N}$ * First find $6\mathbb{N} \cap 8\mathbb{N}$:

$$ \text{LCM}(6, 8): \quad 6 = 2 \times 3, \quad 8 = 2^3 \implies \text{LCM}(6, 8) = 2^3 \times 3 = 24 $$

$$ 6\mathbb{N} \cap 8\mathbb{N} = 24\mathbb{N} $$

$$ \text{[Intermediate intersection: } \mathbf{1\text{ Mark}}\text{]} $$

  • Next intersect with $12\mathbb{N}$:

$$ 24\mathbb{N} \cap 12\mathbb{N} = (\text{LCM}(24, 12))\mathbb{N} $$

Since $12$ divides $24$, $\text{LCM}(24, 12) = 24$.

$$ (6\mathbb{N} \cap 8\mathbb{N}) \cap 12\mathbb{N} = 24\mathbb{N} $$

$$ \text{[Final computation and answer: } \mathbf{1\text{ Mark}}\text{]} $$

Question C3: Deep Power Set and Relation to Cartesian Inclusion

Tag: <span class="step-mark-tag">[NCERT Exemplar, Subjective Proof, 3 Marks]</span>
Priority: ⭐⭐⭐⭐ [High-Yield]

Problem Statement:

Prove that for any two sets $A$ and $B$:

$$ P(A) \cup P(B) \subseteq P(A \cup B) $$

Show by a suitable counterexample that the reverse inclusion:

$$ P(A \cup B) \subseteq P(A) \cup P(B) $$

does not hold in general.

📝 View CBSE Model Solution & Step-Marking Scheme ▼

Model Solution & CBSE Step-Marking Rubric:

Step 1: Direct Proof of $P(A) \cup P(B) \subseteq P(A \cup B)$ * Let $X$ be an arbitrary element of $P(A) \cup P(B)$.

$$ \implies X \in P(A) \quad \text{or} \quad X \in P(B) $$

$$ \text{[Definition of Union: } \mathbf{\tfrac{1}{2}\text{ Mark}}\text{]} $$

  • By definition of power set:

$$ \implies X \subseteq A \quad \text{or} \quad X \subseteq B $$

  • We know that for any sets $A$ and $B$:

$$ A \subseteq (A \cup B) \quad \text{and} \quad B \subseteq (A \cup B) $$

  • By the transitive property of subset inclusion:
  • If $X \subseteq A$, then since $A \subseteq (A \cup B)$, we have $X \subseteq (A \cup B)$.
  • If $X \subseteq B$, then since $B \subseteq (A \cup B)$, we have $X \subseteq (A \cup B)$.
  • In either case:

$$ X \subseteq (A \cup B) \implies X \in P(A \cup B) $$

$$ \text{[Deduction: } \mathbf{\tfrac{1}{2}\text{ Mark}}\text{]} $$

  • Since every $X \in P(A) \cup P(B)$ belongs to $P(A \cup B)$:

$$ P(A) \cup P(B) \subseteq P(A \cup B) $$

$$ \text{[Conclusion: } \mathbf{\tfrac{1}{2}\text{ Mark}}\text{]} $$

Step 2: Counterexample for the reverse inclusion * Let:

$$ A = \{1\} \quad \text{and} \quad B = \{2\} $$

$$ \text{[Constructing Disjoint Sets: } \mathbf{\tfrac{1}{2}\text{ Mark}}\text{]} $$

  • Then:

$$ A \cup B = \{1, 2\} $$

$$ P(A \cup B) = \{\phi, \{1\}, \{2\}, \{1, 2\}\} $$

  • Now compute $P(A)$ and $P(B)$:

$$ P(A) = \{\phi, \{1\}\}, \quad P(B) = \{\phi, \{2\}\} $$

$$ P(A) \cup P(B) = \{\phi, \{1\}, \{2\}\} $$

$$ \text{[Evaluation of both power sets: } \mathbf{\tfrac{1}{2}\text{ Mark}}\text{]} $$

  • Consider the subset $Y = \{1, 2\}$:

$$ Y \in P(A \cup B) $$

However, $Y \notin P(A)$ (since $\{1, 2\} \not\subseteq \{1\}$) and $Y \notin P(B)$ (since $\{1, 2\} \not\subseteq \{2\}$).

$$ \implies Y \notin P(A) \cup P(B) $$

  • Therefore:

$$ P(A \cup B) \not\subseteq P(A) \cup P(B) $$

$$ \text{[Final Counterexample Justification: } \mathbf{\tfrac{1}{2}\text{ Mark}}\text{]} $$

  2. Find the number of families that buy none of the newspapers $A, B$, or $C$. (1.5 Marks)
  3. Find the number of families that buy at least two newspapers. (1.5 Marks)
📝 View CBSE Model Solution & Step-Marking Scheme ▼

Model Solution & CBSE Step-Marking Rubric:

Total number of families, $N = 10,000$. Converting percentages to actual numbers: * $n(A) = 40\% \text{ of } 10,000 = 4,000$ * $n(B) = 20\% \text{ of } 10,000 = 2,000$ * $n(C) = 10\% \text{ of } 10,000 = 1,000$ * $n(A \cap B) = 5\% \text{ of } 10,000 = 500$ * $n(B \cap C) = 3\% \text{ of } 10,000 = 300$ * $n(A \cap C) = 4\% \text{ of } 10,000 = 400$ * $n(A \cap B \cap C) = 2\% \text{ of } 10,000 = 200$

$$ \text{[Correct conversion of data: } \mathbf{\tfrac{1}{2}\text{ Mark}}\text{]} $$

$$ n(A \text{ only}) = n(A) - n(A \cap B) - n(A \cap C) + n(A \cap B \cap C) $$

  • Calculation:

$$ n(A \text{ only}) = 4,000 - 500 - 400 + 200 = 3,300 $$

$$ \text{[Formula and calculation: } \mathbf{\tfrac{1}{2}\text{ Mark}}\text{; Final Answer: } \mathbf{\tfrac{1}{2}\text{ Mark}}\text{]} $$

Part (2): Families buying none of the newspapers * First find the union $n(A \cup B \cup C)$:

$$ n(A \cup B \cup C) = \sum n(A) - \sum n(A \cap B) + n(A \cap B \cap C) $$

$$ n(A \cup B \cup C) = (4000 + 2000 + 1000) - (500 + 300 + 400) + 200 $$

$$ n(A \cup B \cup C) = 7000 - 1200 + 200 = 6,000 $$

$$ \text{[Correct Union Computation: } \mathbf{1\text{ Mark}}\text{]} $$

  • Number of families buying none:

$$ n((A \cup B \cup C)') = N - n(A \cup B \cup C) = 10,000 - 6,000 = 4,000 $$

$$ \text{[Final Answer: } \mathbf{\tfrac{1}{2}\text{ Mark}}\text{]} $$

Part (3): Families buying at least two newspapers * The event "at least two" consists of the three intersections of pairs minus twice the intersection of all three:

$$ n(\text{at least two}) = n(A \cap B) + n(B \cap C) + n(A \cap C) - 2 \cdot n(A \cap B \cap C) $$

$$ \text{[Formula / Decomposition: } \mathbf{1\text{ Mark}}\text{]} $$

$$ n(\text{at least two}) = 500 + 300 + 400 - 2(200) $$

$$ n(\text{at least two}) = 1200 - 400 = 800 $$

$$ \text{[Correct Computation: } \mathbf{\tfrac{1}{2}\text{ Mark}}\text{]} $$

1. Speed Hacks & Fast Solving Shortcuts

1.1 Venn Diagram "Region Weight" Method (3 Sets in $< 90$ Seconds)

Do not solve long simultaneous linear equations for 3-set word problems. Use concentric filling from the innermost region out: 1. Always label the 8 disjoint regions directly: - Center: $r_7 = n(A \cap B \cap C)$ - Two-set-only overlaps:

$$ r_4 = n(A \cap B) - r_7, \quad r_5 = n(B \cap C) - r_7, \quad r_6 = n(A \cap C) - r_7 $$

  • Set-only regions:

$$ r_1 = n(A) - (r_4 + r_6 + r_7), \quad \text{etc.} $$

  1. Formula Shortcuts for Direct Calculations:
  2. Number of elements in exactly two sets:

$$ \sum n(A \cap B) - 3n(A \cap B \cap C) $$

  • Number of elements in exactly one set:

$$ \sum n(A) - 2\sum n(A \cap B) + 3n(A \cap B \cap C) $$

  • Number of elements in at least two sets:

$$ \sum n(A \cap B) - 2n(A \cap B \cap C) $$

1.2 Binary String Indexing for Power Set Generation

To write $\mathcal{P}(A)$ for $A = \{a, b, c\}$ without missing subsets or duplicate counts: - An element count of $n \implies 2^n$ subsets. - Count in binary from $0$ to $2^n - 1$: - $000 \to \phi$ - $001 \to \{c\}, \ 010 \to \{b\}, \ 011 \to \{b, c\}$ - $100 \to \{a\}, \ 101 \to \{a, c\}, \ 110 \to \{a, b\}, \ 111 \to \{a, b, c\}$ - Speed Check: Group subsets by cardinality: $\binom{n}{0} + \binom{n}{1} + \dots + \binom{n}{n}$. For $n=3$, group counts are $1 + 3 + 3 + 1 = 8$.

1.3 Subsets of Number Systems: The Nested Chain Trick

Memorize the hierarchy unconditionally:

$$ \mathbb{N} \subset \mathbb{W} \subset \mathbb{Z} \subset \mathbb{Q} \subset \mathbb{R} \subset \mathbb{C}, \quad \text{and} \quad \mathbb{T} = \mathbb{R} \setminus \mathbb{Q} \quad (\text{Irrational numbers}) $$

  • Quick intersections: $\mathbb{Q} \cap \mathbb{T} = \phi$, $\mathbb{Q} \cup \mathbb{T} = \mathbb{R}$, $\mathbb{Z} \cap \mathbb{N} = \mathbb{N}$.

1.4 Modulo & Divisibility Multiples (LCM Principle)

When sets are defined as multiples of integers: - Let $A_k = \{x : x \text{ is a multiple of } k, x \in \mathbb{N}\}$. - $A_p \cap A_q = A_{\text{LCM}(p, q)}$. - Example: Multiples of 4 and 6:

$$ A_4 \cap A_6 = A_{\text{LCM}(4,6)} = A_{12} $$

1.5 Cartesian Dimension Quick Calculation

  • $n(A \times B) = n(A) \cdot n(B)$
  • Total number of relations from $A$ to $B$: $2^{n(A) \cdot n(B)}$
  • Total non-empty subsets / relations: $2^{n(A) \cdot n(B)} - 1$

2. Examiner Traps & Common Board Evaluation Mistakes

2.1 The Deadly Trap: Element ($\in$) vs. Subset ($\subset$)

Board evaluators penalize confusion between element membership and subset containment. Let $A = \{1, 2, \{3, 4\}, 5\}$:

Expression Truth Value Examiner Evaluation Comment
$\{3, 4\} \in A$ True $\{3, 4\}$ is a single monolithic element inside $A$.
$\{3, 4\} \subset A$ False The elements 3 and 4 are not independent members of $A$.
$\{\{3, 4\}\} \subset A$ True The set containing the element $\{3, 4\}$ is indeed a subset.
$1 \subset A$ False $\mathbf{-\frac{1}{2} \text{ Mark}}$: Numbers cannot be subsets; must write $\{1\} \subset A$.
$\phi \in A$ False $\phi$ is an element only if explicitly listed (e.g., $A = \{\phi, 1\}$).
$\phi \subset A$ True Empty set is a subset of every set.

2.2 The Empty Set Notation Trap

  • Correct: $\phi$ OR $\{\}$
  • Incorrect: $\{\phi\}$ is NOT the empty set! It is a singleton set containing the empty set ($n(\{\phi\}) = 1$). Writing $\{\phi\}$ for a null set gets a $0$ mark penalty on that step.

2.3 Interval Brackets in Set-Builder Form

CBSE awards $0$ marks for incorrect bracket bounds: - $A = \{x \in \mathbb{R} : a \le x < b\} \implies [a, b)$ - Trap: Forgetting that interval notation applies only to real numbers ($\mathbb{R}$). - If $x \in \mathbb{Z}$ and $-2 \le x < 3$, writing $[-2, 3)$ is mathematically incorrect. - The answer must be in roster form: $\{-2, -1, 0, 1, 2\}$.

2.4 Symmetric Difference Ambiguity

$$ A \Delta B = (A \setminus B) \cup (B \setminus A) = (A \cup B) \setminus (A \cap B) $$

  • Evaluator Trap: Students frequently write $A - B = B - A$. Subtraction of sets is non-commutative.

2.5 De Morgan's Law Proof Step-Marking Scheme

When asked: "Prove that $(A \cup B)' = A' \cap B'$ using theoretical set logic" (frequent 3-mark question):

  • Step 1 (1.5 Marks): Show $(A \cup B)' \subseteq A' \cap B'$
  • Let $x \in (A \cup B)' \implies x \notin (A \cup B)$
  • $\implies x \notin A \mathbf{and} x \notin B$ (Examiner note: writing "or" here forfeits all remaining marks)
  • $\implies x \in A' \text{ and } x \in B' \implies x \in (A' \cap B')$
  • Therefore, $(A \cup B)' \subseteq A' \cap B'$.
  • Step 2 (1.5 Marks): Show $A' \cap B' \subseteq (A \cup B)'$
  • Let $y \in A' \cap B' \implies y \in A' \text{ and } y \in B'$
  • $\implies y \notin A \text{ and } y \notin B \implies y \notin (A \cup B)$
  • $\implies y \in (A \cup B)'$.
  • Therefore, $A' \cap B' \subseteq (A \cup B)'$.
  • Step 3 (Conclusion): From (1) & (2), $(A \cup B)' = A' \cap B'$. (Skipping Step 2 and writing "similarly" results in a $-1$ mark deduction).

3. Golden Points to Remember (NCERT Theorems & High-Yield Truths)

  1. Power Set of Empty Set:
  2. If $A = \phi$, then $n(A) = 0$.
  3. $\mathcal{P}(A) = \{\phi\}$.
  4. Cardinality: $n(\mathcal{P}(A)) = 2^0 = 1$.

  8. $A \setminus B = A \cap B'$
  9. $n(A \setminus B) = n(A) - n(A \cap B)$ (Do not write $n(A) - n(B)$; this holds only if $B \subseteq A$)

  10. $n(A \cup B) = n(A \setminus B) + n(B \setminus A) + n(A \cap B)$

  11. Disjoint Sets:

  12. Two sets $A$ and $B$ are disjoint if and only if $A \cap B = \phi \implies n(A \cap B) = 0$.

  13. For pairwise disjoint sets: $n(A \cup B \cup C) = n(A) + n(B) + n(C)$.

  14. Universal Set Boundary Condition:

  15. For any set $A$, $A \cup A' = U$ and $A \cap A' = \phi$.
  16. $(U)' = \phi$ and $\phi' = U$.

  17. $(A')' = A$ (Law of Double Complementation).

  18. Subsets Count Distinction:

  19. Total number of subsets of set with $n$ elements $= 2^n$.
  20. Total number of proper subsets $= 2^n - 1$ (excludes the set itself).
  21. Total number of non-empty proper subsets $= 2^n - 2$ (excludes both $\phi$ and the set itself).

$$ A \cup \phi = A, \quad A \cap U = A $$

| $\phi$ acts as additive identity; $U$ acts as multiplicative identity. | | Domination Laws |

$$ A \cup U = U, \quad A \cap \phi = \phi $$

| Often useful in simplifying complex set statements. | | Commutative Laws |

$$ A \cup B = B \cup A, \quad A \cap B = B \cap A $$

| Note: Difference is NOT commutative: $A \setminus B \ne B \setminus A$. | | Associative Laws |

$$ (A \cup B) \cup C = A \cup (B \cup C) $$

$$ (A \cap B) \cap C = A \cap (B \cap C) $$

| Connectives must be identical to associate. | | Distributive Laws |

$$ A \cup (B \cap C) = (A \cup B) \cap (A \cup C) $$

$$ A \cap (B \cup C) = (A \cap B) \cup (A \cap C) $$

| Always check cross-operators: union distributes over intersection & vice versa. | | De Morgan's Laws |

$$ (A \cup B)' = A' \cap B' $$

$$ (A \cap B)' = A' \cup B' $$

| In word problems: "neither $A$ nor $B$" translates to $(A \cup B)' = A' \cap B'$. | | Difference Equivalence |

$$ A \setminus B = A \cap B' = A \setminus (A \cap B) $$

| Convert difference into intersection of complements before expanding. | | Cardinality of 2 Sets |

$$ n(A \cup B) = n(A) + n(B) - n(A \cap B) $$

| If disjoint, $n(A \cap B) = 0$. | | Cardinality of 3 Sets |

$$ \begin{aligned} n(A \cup B \cup C) &= n(A) + n(B) + n(C) \\ &\quad - n(A \cap B) - n(B \cap C) - n(C \cap A) \\ &\quad + n(A \cap B \cap C) \end{aligned} $$

| Sign alternates: $+$, then $-$, then $+$. Missing the last term is the single most common mistake. | | Exactly 1 of 3 Sets |

$$ \begin{aligned} n(\text{only 1}) &= \sum n(A) - 2\sum n(A \cap B) \\ &\quad + 3n(A \cap B \cap C) \end{aligned} $$

| Standard 4-mark question shortcut. | | Exactly 2 of 3 Sets |

$$ n(\text{only 2}) = \sum n(A \cap B) - 3n(A \cap B \cap C) $$

| Direct evaluation shortcut. | | Power Set Cardinality |

$$ n(\mathcal{P}(A)) = 2^{n(A)} $$

| $A$ must be a finite set. | | Cartesian Product |

$$ n(A \times B) = n(A) \cdot n(B) $$

| $A \times B \ne B \times A$ unless $A = B$ or one is $\phi$. |
